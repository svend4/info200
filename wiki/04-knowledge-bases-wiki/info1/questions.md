## 3. Что делать с криптографией в `encryption_manager.py`?

**Варианты ответов:**
- А. Это учебная имитация — модуль не предназначен для реального использования.
- Б. Недосмотр — нужно сделать `cryptography` обязательной зависимостью.
- В. Модуль вообще стоит удалить.

**Варианты дальнейших действий:**
- При А: добавить в docstring и README тулкита предупреждение «NOT FOR PRODUCTION — educational simulation», убрать слова enterprise-grade.
- При Б: удалить `_xor_encrypt`/`_encrypt_simple`, поднимать ImportError без `cryptography`, добавить тест-раундтрип (пример уже есть в test_security_integration.py — он станет полезным после починки импортов).
- При В: удалить security-пакет и упоминания шести модулей из CHANGELOG/README.
