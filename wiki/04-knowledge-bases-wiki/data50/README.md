# data50 — заготовка «info» с единственным обзором статьи об ИИ-аватарах

## Обзор

**data50** — один из многочисленных «info»-репозиториев профиля svend4 (описание на GitHub: «info, аи аватары»). Фактически это почти пустой репозиторий: в нём всего два markdown-файла — минимальный `README.md` (две строки: заголовок и слово «info») и один содержательный документ `review-habr-article.md` — аналитический обзор статьи с Хабра об ИИ-клоне (цифровом двойнике) CTO компании Extreme Networks. Кода, данных, конфигураций, документации проекта нет.

## Назначение и идея

Судя по описанию репозитория («аи аватары») и содержимому единственного содержательного файла, задумка — собирать информацию/аналитику по теме **ИИ-аватаров и цифровых двойников людей** (в частности, руководителей). Обзор `review-habr-article.md` посвящён кейсу: CTO Extreme Networks Набил Бухари обучил ИИ-агента на своих личных коммуникациях и документах, и агент взял на себя ~80% рутинных ревью проектов, достигнув 85–90% совпадения со стилем вопросов оригинала. Обзор структурирован: резюме, ключевые факты, таблица метрик, анализ сильных сторон и рисков (прозрачность, воспроизведение предвзятостей, масштабируемость), выводы об отраслевых последствиях.

Иными словами, репозиторий — это «первая карточка» потенциальной тематической базы знаний по ИИ-аватарам, которая так и не была развита дальше одного обзора.

## Как устроено (архитектура)

Архитектуры как таковой нет — плоская структура из двух файлов в корне:

- `README.md` — заглушка (заголовок `# data50` + слово `info`);
- `review-habr-article.md` — обзор статьи Habr (~2,7 КБ, на английском языке), сгенерирован с помощью Claude: файл пришёл через ветку `claude/review-habr-article-Mc4AC` и PR #1, автор коммита — `claude`, в конце файла пометка «*Review generated: 2026-02-04*».

Ни папок, ни лицензии, ни CI, ни `.gitignore` нет (проверено запросами к raw-контенту — 404 для `CLAUDE.md`, `LICENSE`, `.github/workflows`, `.gitignore`, `docs/`).
