# Структура data50

Репозиторий имеет предельно простую, плоскую структуру: два markdown-файла в корне, никаких папок.

```text
data50/
├── README.md                 # заглушка: "# data50" + строка "info" (2 строки)
└── review-habr-article.md    # единственный содержательный файл (~2,7 КБ):
                              # обзор статьи Habr об ИИ-клоне CTO Extreme Networks,
                              # сгенерирован Claude 2026-02-04, влит через PR #1
```

Отсутствуют (проверено — raw-запросы возвращают 404): `CLAUDE.md`, `LICENSE`, `.gitignore`, `.github/` (workflows), `docs/`.

## Ключевые файлы

| Файл | Что делает / содержит |
|---|---|
| `README.md` | Две строки: заголовок `# data50` и слово `info`. Ни описания цели, ни навигации. Не отражает даже описание репозитория на GitHub («info, аи аватары»). |
| `review-habr-article.md` | Структурированный обзор новости Habr (https://habr.com/ru/news/992546/, публикация 04.02.2026): CTO Extreme Networks создал ИИ-агента, обученного на своих документах и коммуникациях. Разделы: Summary; Key Facts (данные обучения, цель, срок 7–8 месяцев); таблица Results (ИИ обрабатывает ~80% ревью, совпадение стиля 85–90% против стартовых 50%); Analysis (4 сильных стороны, 4 риска: единственная точка обучения, прозрачность для сотрудников, масштабируемость, воспроизведение предвзятостей; отраслевые последствия — тренд «цифровых двойников» руководителей); Conclusion. Написан на английском, в конце пометка о генерации: «Review generated: 2026-02-04». |

## Особенности организации

- **Контент создан ИИ-агентом через PR-процесс**: файл обзора добавлен коммитом автора `claude` из ветки `claude/review-habr-article-Mc4AC`, влит владельцем через merge PR #1. Это единственный видимый рабочий процесс в репозитории — типовой паттерн «задача Claude → PR → merge», встречающийся и в других репозиториях профиля svend4.
- **Нет никакой систематизации**: обзор лежит в корне без папки вида `reviews/`, без индекса, без тегов/фронтматтера — при добавлении второго-третьего обзора структуру пришлось бы вводить с нуля.
- **Разнобой языков**: описание репозитория и тематика — на русском («аи аватары»), сам обзор — на английском, README не говорит ничего.
- История: 3 коммита, одна ветка `main`; между созданием контента (февраль 2026) и мерджем PR (апрель 2026) — пауза более двух месяцев, что говорит об эпизодическом внимании к репозиторию.
