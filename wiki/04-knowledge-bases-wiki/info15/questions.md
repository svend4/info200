**Варианты ответов**

- В. Хотел бы, но нет автоматизации — вручную не потянуть.

**Варианты дальнейших действий**
- При А: начать с синхронизации CLAUDE.md с реальной структурой (иначе агент-обновлятор запутается), затем настроить регулярный агентный прогон.
- При Б: зафиксировать релиз v1.0, добавить в README пометку «снапшот на апрель 2026», перевести репозиторий в режим архива-датасета (сценарий 3 из рекомендаций).
- При В: реализовать конвейер yt-dlp → raw/ → Claude Code → PR (сценарий 1); это разовая инвестиция, дальше вики живёт сама.

## 2. Где исходные данные (raw-слой)? Из чего компилировались статьи?

**Варианты ответов**
- А. Исходники были в сессии агента (транскрипты/выгрузки) и не закоммичены.
- Б. Агент работал прямо по странице YouTube-канала, отдельных исходников не было.
- В. Исходники лежат в другом репозитории/локально.

**Варианты дальнейших действий**
- При А: восстановить и закоммитить raw-слой — вики станет воспроизводимой и проверяемой.

- При В: перенести в info15 или дать ссылку в README; без этого заявленная архитектура «raw + wiki + CLAUDE.md» реализована на две трети.

**Варианты дальнейших действий**

- При В: минимально — пометить v2 как draft в её README; лучше — слить или удалить.
