## Ключевые файлы и модули

| Файл/папка | Что делает / содержит |
|---|---|
| `chat_export/` (153 txt) | Полный текст 1105 разговоров; единый машиночитаемый формат с разделителями `=…= РАЗГОВОР N/1105` |
| `prepare_for_infom.py` | Единственный код: `THEME_RULES` (17 тем × ключевые слова × «архетипы» вида MSCF/ADCO), `classify_conversation()`, `extract_key_concepts()` (TF без стоп-слов), `parse_all_conversations()` (фильтр тривиальных: <200 символов или <2 сообщений), `build_infom_graph()` (ноды-темы, ноды-проекты depth≥3, ноды-концепции ≥3 разговоров и ≥2 тем, рёбра тема–тема через общие концепции) |
| `infom_import.json` | Метаданные: 1091 содержательный разговор, 100 глубоких, 17 тем, 290 сквозных концепций; 197 нод / 576 рёбер |
| `analysis_01_overview.md` | Ядро аналитики: распределение по глубине (100 разговоров >100 КБ), топ-10 разговоров (лидер — 1766 сообщений / 4,1 МБ), карта кластеров с потенциалом |
| `part12_catalog.md` | Реестр 88 тем: кластер A–J, приоритет А/Б/В с баллами, MVP-номер, перекрёстные связи |
| `monorepo/00_index/clusters_overview.md` | Таблица 11 кластеров + соответствие аналитическим кластерам A–J + рейтинги коммерческого и патентного потенциала |
| `monorepo/superprojects/README.md` | 5 суперпроектов с бюджетами MVP (€100–220K) и рекомендуемой последовательностью запуска |
| `monorepo/01_social_law/01_persoenliches_budget/README.md` | Образец карточки-темы: суть, что собрано, параграфы SGB IX, типичные ошибки ведомств, варианты монетизации |
| `MANIFEST.md` | Контекст и мотивация всего репозитория; датирован 27.03.2026 |

## Особенности организации

- **Слоистость и неизменность сырья**: явное правило (в `monorepo/README.md`) — исходные файлы не переписываются, новая структура только индексирует их. Данные и аналитика чётко разделены.
- **Единый шаблон карточек**: каждый кластер — `README.md` + `map.md` + `next_steps.md`; каждая тема — README с одинаковыми разделами. Перекрёстные ссылки вида `[см. 02_ai_agents/01_micro_agents]`.
- **Двойная система классификации**: аналитические кластеры A–J (в part11/part12) и «продуктовые» кластеры 01–10 (в monorepo) с таблицей соответствия — избыточно, но задокументировано.
- **Авторская маркировка разговоров** числовыми кодами (111 = соцправо, 999 = ИИ и т.д.) использована как одна из осей анализа.
- **Код — вспомогательный**: Python здесь не продукт, а конвейер экспорта в граф; GitHub определяет язык репозитория как «Python 100%» только потому, что это единственный файл кода.
