**Варианты ответов:**
- А. Канонический — `prima-cpp-vulkan-porting-guide.html`, второй — черновик/ранняя версия.
- Б. Они дополняют друг друга (разные ракурсы: план vs код) и оба нужны.
- В. Это два независимых прогона генерации, осознанного выбора не было.

**Варианты дальнейших действий:**
- При А: пометить второй как архив (баннер + перенос в `archive/`) или удалить; в README оставить одну строку.
- При Б: явно описать в README разделение ролей и добавить взаимные ссылки «см. также» в оба файла.
- При В: провести дифф-сравнение содержимого, слить лучшее в один документ, второй удалить.
