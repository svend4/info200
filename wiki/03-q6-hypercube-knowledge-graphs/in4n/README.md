# in4n — InfoAquarium: динамический граф-«информационный аквариум»

## Обзор

**in4n** (внутреннее имя проекта — **InfoAquarium**) — экспериментальная визуализация знаний в виде живого графа: узлы — понятия или заметки, рёбра — связи, а треугольники Делоне между узлами образуют цветной «ландшафт» (горы, долины). По рёбрам движутся светящиеся агенты-«путешественники», оставляющие феромонные следы (алгоритм муравьиной колонии, ACO). Метафора автора: «стеклянный муравейник», по которому путешествуешь сквозь смысл.

Репозиторий содержит **три независимые реализации одной идеи**:

1. `1-browser/` — автономный прототип: один HTML-файл (813 строк) с Canvas 2D, без сборки;
2. `2-react/` — React 18 + Vite + `react-force-graph` (Three.js, 3D) + Delaunay-террейн;
3. `3-obsidian/` — плагин Obsidian: граф строится из реальных заметок хранилища (заметки = узлы, вики-ссылки `[[...]]` = рёбра).

## Назначение и идея

Проект исследует, как сделать граф знаний не статичной схемой, а **обитаемым пространством**:

- **Физика каждый кадр**: отталкивание (Кулон) + пружины (Гук) + демпфирование — граф «дышит»;
- **Путешественник**: клик по узлу строит BFS-маршрут, агент движется только по рёбрам — «рёбра = дороги мира»;
- **Феромоны (ACO)**: популярные пути накапливают «запах» и светятся ярче, следы испаряются со временем;
- **Гиперболическая проекция** (диск Пуанкаре, преобразование Мёбиуса) — «мир схлопывается внутрь», клавиша H;
- **Игровой режим** (клавиша G): игрок против четырёх ботов наперегонки добирается до целевого узла, со счётом и звуком (Web Audio, пентатоника C);
- **Дополнительные режимы** прототипа: ячейки Вороного (V), «кроссворд» — слова на рёбрах (C), интерактивный редактор узлов и рёбер (E);
- **Время как измерение** (React-версия): ползунок «эпох» фильтрует граф по активным группам понятий;
- **Семантический зум** (React-версия): при приближении камеры к узлу всплывает карточка с описанием и числом связей.

Демо-данные — философский мини-граф из 12–15 русскоязычных понятий («Время», «Пространство», «Смысл», «Путь»…). В Obsidian-версии данные реальные — заметки пользователя.

## Как устроено (архитектура)

Три реализации не разделяют код — каждая самодостаточна, общие алгоритмы (физика, BFS, Мёбиус, феромоны) продублированы:

- **1-browser** — vanilla JS в одном `index.html`: Canvas 2D, шесть режимов, мульти-агенты, редактор графа, Web Audio. Зависимости `delaunator` и `d3-delaunay` грузятся с CDN (нужен интернет).
- **2-react** — `App.jsx` (339 строк) оборачивает `ForceGraph3D`; поверх WebGL — 2D-канвас `TerrainOverlay` (Делоне/Вороной по спроецированным координатам узлов), компоненты `InfoPanel` (ползунок эпох), `SemanticZoom`, `AgentHUD`, хук `useAudio`. 3D-рельеф: высота узла `fz = число связей × 8` плюс «колонны-горы» (цилиндры THREE.js).
- **3-obsidian** — `src/main.ts` (634 строки, TypeScript): класс `AquariumView extends ItemView`, чтение заметок через `MetadataCache`, собственная физика и рендер на Canvas 2D, гиперболический режим, ACO-феромоны, демо-граф при пустом хранилище. Сборка esbuild в `main.js`.

Подробности — в [structure.md](structure.md).

## Статус и активность

- Всего **7 коммитов**, все — **28 марта 2026** (один день разработки): начальный коммит владельца + 2 слитых PR из ветки `claude/dynamic-graph-visualization-OLZGo` (код генерировался Claude, мержил svend4).
- С конца марта 2026 активности нет (на дату аудита 2026-07-02 — свыше 3 месяцев тишины).
- Статус: **экспериментальный прототип**, работоспособный по коду, но не проверявшийся автором в бою (тестов, CI, релизов нет).
- Перепроверка README: дорожная карта в нём **устарела** — 4 из 5 пунктов (гиперболическая проекция, феромоны ACO, семантический зум, 3D-рельеф) фактически реализованы последующими коммитами, чекбоксы не проставлены; не реализован только мультиплеер по WebSocket. Подробнее — в [assessment.md](assessment.md).
