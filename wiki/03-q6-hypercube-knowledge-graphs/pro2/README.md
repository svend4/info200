# pro2 — YiJing-Transformer: трансформер с геометрией гиперкуба Q6 (гексаграммы И-Цзин)

## Обзор

**pro2** — самый крупный и технически насыщенный исследовательский репозиторий профиля svend4: Python-пакет `yijing_transformer` (версия 0.50.0, «Advanced Alpha»), реализующий трансформерные языковые модели с **геометрическим индуктивным смещением** на основе 64 гексаграмм И-Цзин, математически изоморфных вершинам 6-мерного гиперкуба Q6 = {-1,+1}⁶.

Это не эзотерика, а честная математика: 8 триграмм = вершины куба {-1,+1}³ (группа Z₂³), 64 гексаграммы = все 2⁶ вершин гиперкуба. Проект исследует, улучшает ли встраивание этой заданной (не обучаемой) структуры эффективность обучения и интерпретируемость малых трансформеров.

Масштаб проверен по факту: ~90 тысяч строк Python (заявлено в `docs/FULL_AUDIT_REPORT.md`, выборочно подтверждено: `models/model.py` — 2198 строк, `geometry/routing.py` — 1917, `quantizers.py` — 1222, `hierarchical_moe.py` — 1160), **~1971 тест-функция** в 22 файлах `test_*.py` (посчитано напрямую по `def test_`; в каталоге `tests/` 23 `.py`-файла с учётом `__init__.py`), 494 коммита, 18 файлов документации в `docs/` плюс 15+ md-файлов в корне.

## Назначение и идея

Ключевая цепочка идей проекта:

```
64 гексаграммы И-Цзин ≅ вершины Q6 = {-1,+1}⁶
      ↓
токены проецируются в Q6-пространство через 64 архетипных «полюса»
      ↓
квантизация по расстоянию Хэмминга (а не евклидову)
      ↓
тензорная факторизация: softmax по 64 точкам = два softmax по 8
(верхняя × нижняя триграмма) → заявлено 3.75× ускорение
      ↓
генерация = шаги по графу Бян-Гуа (рёбра = флип одного бита)
```

Реализовано **6+ моделей** (YiJingGPT, Variant3GPT, HierarchicalMoE Q2→Q3→Q6, HierarchicalE2, NautilusYiJing, VanillaGPT-бейзлайн), **12–13 квантизаторов** (YiJing, Factored, Matryoshka, Ternary, E8 и др.), 15+ паттернов внимания, десятки схем маршрутизации (лучший результат — `AbrialeBridgeMediator`, PPL 1.24 против 2.94 у бейзлайна на синтетическом корпусе).

Вторая линия — **NautilusMoME** (~3M параметров): мультидоменная Mixture-of-Micro-Experts с 6 экспертами (CODE, RECON, SYSTEM, MATH, HUMAN, INFO), обучаемая на корпусе из других репозиториев профиля svend4 (`corpus_loader.py` — 8 источников). Папка `nautilus/` содержит «портал» — единую точку входа в экосистему svend4 с адаптерами к репо info1, pro2, meta, data2, data7.

Проект интегрирует 7 теоретических источников (Склярова, Фомюк, Андреев, Касаткин, Герман/GERMES, Беляев, SOLAN) — каждому соответствуют реальные модули кода.

## Как устроено (архитектура)

Три слоя репозитория:

1. **Пакет `yijing_transformer/`** — устанавливаемый (`pip install -e .`), с CLI-командами (`yijing-train`, `yijing-wikitext`, `yijing-extensions`, `yijing-downstream`), подпакетами `models/` (включая `models/geometry/` — ядро: core, quantizers, attention, routing, q6_algebra, kasatkin_router, interlingua_fixed), `training/` (десятки утилит v12–v52 через bridge-модули), `inference/`, `data_utils/`, `tokenizer/` (Char/BPE/Glyph-SOLAN), `tests/` (~1971 тест).
2. **Корень: ~24 скрипта экспериментов** — самообучение (`self_train*.py`, 3 стадии), «Алгоритм Скарабея» (figure-8 обход Q6), мультиагентные схемы (`nautilus_4agent.py`, `nautilus_15agent.py`, `roundabout.py`, `multi_salesman.py`), `pipeline.py` (3-фазный curriculum), `bench_all.py` — плюс **13+ чекпоинтов .pt прямо в git** (~19 МБ каждый, проверено: `hmoe_curriculum.pt` = 18,99 МБ) и 30+ JSON-логов экспериментов.
3. **`experiments/`, `docs/`, `nautilus/`** — валидационные скрипты с логами, 18 файлов документации, портал экосистемы.

Подробнее — в [structure.md](structure.md).

## Статус и активность

- **494 коммита** на main; последняя активность **19.04.2026** (merge PR #86/#85 из веток `claude/*` — разработка ведётся через Claude Code с pull-request'ами). Интенсивная работа в марте–апреле 2026.
- 1 звезда, 0 форков — проект одного автора.
- В репозитории есть **собственные самоаудиты** (`docs/IMPLEMENTATION_STATUS.md`, `docs/FULL_AUDIT_REPORT.md`, `REPORT-v60-v61-status.md`) — перепроверка показала, что они на удивление честны: числа тестов (заявлено 1957–1987, посчитано 1971), размеры файлов (например, `e2_inference.py` — ровно 451 строка, как заявлено) и размеры чекпоинтов совпадают. Сам аудит прямо признаёт: **все бенчмарки — toy-scale** (d_model=128, 800 шагов, <100 K токенов), «не демонстрация production-качества».
- Важное расхождение: README заявляет лицензию MIT, но **файла LICENSE в репозитории нет** (проверено: 404 по всем вариантам имени). CI тоже отсутствует.
