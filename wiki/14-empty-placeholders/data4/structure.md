# Структура data4

Репозиторий состоит из одного файла. Полное дерево:

```text
data4/
└── README.md    # 2 строки: заголовок "# data4" и слово "Soz".
                 # Автосгенерированный при создании репозитория README,
                 # дополненный одним словом-меткой темы ("соц").
```

## Ключевые файлы

| Файл | Содержимое | Роль |
|---|---|---|
| `README.md` | `# data4` + `Soz` | Единственный файл; фактически плейсхолдер. Не описывает ни назначение, ни план проекта. |

## Чего в дереве нет (проверено зондированием raw-путей, все 404)

- `CLAUDE.md`, `docs/` — нет никакой документации;
- `package.json`, `app.py`, `main.py`, `src/index.js`, `index.html` — нет ни кода, ни намёка на выбранный стек;
- `LICENSE` — лицензия отсутствует;
- каких-либо папок нет вообще — корень содержит один файл.

## Особенности организации

- Единственная ветка `main`, единственный коммит «Initial commit» (2025-12-28).
- GitHub не определяет язык репозитория — кода нет.
- Вся «организация» проекта сводится к имени репозитория и описанию на GitHub («Soz соц апп - программ перс бюджет»); внутри репозитория эта идея никак не материализована.
- Именование вписывается в серию `data2…data70` профиля svend4 — короткие репозитории-контейнеры под отдельные идеи; data4, судя по всему, — зарезервированное место под «социальное приложение персонального бюджета», к которому автор пока не приступил.
