## Назначение и идея

Единственные источники информации о замысле — описание репозитория и слово «Soz» в README:

- **«Soz соц апп»** — социальное приложение. Приставка «Soz/соц» перекликается с репозиторием `soz150` («info соц, writing os») того же профиля, т.е. это, вероятно, часть «социальной» линейки проектов автора.
- **«программ перс бюджет»** — программа персонального бюджета: учёт личных доходов/расходов, планирование трат.

Таким образом, идея — **приложение для ведения личного бюджета с социальным компонентом** (например, совместные бюджеты, обмен шаблонами трат, семейный учёт). Однако это реконструкция по 5 словам описания; сам замысел в репозитории нигде не раскрыт — ни спецификации, ни макетов, ни плана. Пометка: **не проверено** — подтвердить трактовку может только владелец.
