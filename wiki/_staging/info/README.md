# info — русскоязычная база знаний «Системы и концепции» (параллели и соответствия)

## Обзор

Репозиторий **svend4/info** — это чисто документационная база знаний на русском языке: **39 markdown-документов в 10 тематических категориях** плюс `README.md` и полный индекс `ИНДЕКС.md`. Совокупный объём — около **17 250 строк / ~758 КБ** текста. Кода в репозитории нет вообще — это энциклопедический корпус.

Описание репозитория на GitHub: *«info, параллели, соответствие предметов и явлений, псевдо ии»*. Ключевая идея — не просто справочник, а систематизация **соответствий между системами**: число 7 связывает цвета радуги, дни недели, ноты и чудеса света; число 4 — стихии, времена года и стороны света. Документ `06-классификации/01-классификация-по-количеству.md` — концептуальное ядро этой идеи: классификация мировых концепций по количеству элементов (1 — единство, 2 — дуальность, 3 — триада и т.д.).

## Назначение и идея

Заявленные цели (из README репозитория):

- **Образование** — справочный материал, источник для рефератов, систематизация знаний;
- **Исследования** — база для сравнительного анализа, культурные/исторические контексты, междисциплинарные связи;
- **Общее развитие** — кругозор, символизм, культурная грамотность.

Скрытая (заявленная в описании, но не реализованная в коде) цель — «**псевдо ИИ**»: судя по всему, корпус задуман как знаниевая основа для правило-ориентированной системы соответствий («параллели, соответствие предметов и явлений»). Никакого движка, парсера или структурированных данных (JSON/YAML) для этого в репозитории пока нет — соответствия существуют только как текст.

## Как устроено (архитектура)

Плоская, строго нумерованная структура: 10 папок-категорий `01-числовые-системы` … `10-технологии-и-компьютеры`, внутри каждой — нумерованные md-документы. Навигация двухуровневая: `README.md` (обзор + changelog версий 1.0→2.2) и `ИНДЕКС.md` (620 строк, аннотированные ссылки на все 39 документов).

Каждый документ самодостаточен и однотипен: введение → тематические разделы с маркированными списками фактов → «Ключевые вехи/даты» → «Связанные темы» (перекрёстные ссылки на другие документы, включая ссылки-заглушки `#` на *будущие* документы — например, «Алгоритмы и структуры данных»). Документы выросли от компактных (~90 строк про числа 1–10) до объёмных (1169 строк «История компьютеров», 938 строк «Языки программирования») — качество и глубина заметно росли с каждой «версией».

Весь контент создан ИИ: 14 из 16 коммитов авторства **claude**, влиты владельцем через PR #1.
