## Ключевые файлы и их роль

| Файл / модуль | Что делает |
|---|---|
| `README.md` | Витрина: описание, ASCII-дерево структуры, сценарии использования, статистика («39 документов, 10 категорий»), подробный changelog версий 1.0–2.2 с перечислением содержимого каждого добавления |
| `ИНДЕКС.md` | Единая точка навигации: для каждого из 39 документов — ссылка + аннотация из 3–6 пунктов |
| `06-классификации/01-классификация-по-количеству.md` | Смысловое ядро репозитория: сквозная таблица соответствий «число → системы» (1=монотеизм/монархия, 2=инь-ян/дуализм, 3=Троица/Тримурти/3 измерения, 7=радуга/дни/ноты…) — именно то, что в описании названо «параллели, соответствие предметов и явлений» |
| `10-технологии-и-компьютеры/*` | Новейшие и наиболее проработанные документы (v2.1–2.2): по сути мини-учебники с датами, цифрами и примерами кода (Hello World на 8 языках) |

## Особенности организации

1. **Строгая нумерация** папок (`01-`…`10-`) и файлов внутри — порядок чтения задан явно; имена файлов и папок — кириллицей (потенциальная проблема для некоторых инструментов/ОС и URL-кодирования).
2. **Единый шаблон документа**: введение → разделы со списками фактов → «Ключевые вехи» → «Связанные темы» с относительными ссылками; в новых документах встречаются ссылки-заглушки `[Алгоритмы и структуры данных](#) *(будущий документ)*` — задел на продолжение.
3. **Версионирование через changelog в README**, а не через git-теги: каждая «версия» (1.0…2.2) — это один коммит-добавление; сообщения коммитов повторяют номера версий.
4. **Генерация ИИ**: 14 из 16 коммитов — автор `claude`; вся работа влита одним PR (#1, ветка `claude/review-repository-JDxmF`), merge 25.01.2026.
5. **Перекрёстные связи** между документами (число 7 в радуге ↔ днях недели ↔ нотах) — но только в виде текста и ссылок, без машиночитаемого слоя.
