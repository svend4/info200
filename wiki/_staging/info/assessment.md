# Характеристика и оценка info

## Что есть

- **Полный, консистентный корпус из 39 документов в 10 категориях** — все заявленные файлы реально существуют (проверено пофайлово по raw-ссылкам, 41/41 HTTP 200, включая README и ИНДЕКС).
- **Рабочая навигация**: `ИНДЕКС.md` (620 строк) с аннотациями на каждый документ; относительные ссылки между документами работают в рендере GitHub.
- **Существенный объём**: ~17 250 строк / ~758 КБ русскоязычного энциклопедического текста; поздние документы очень детальны (`10-технологии-и-компьютеры/01-история-компьютеров.md` — 1169 строк с датами, цифрами, персоналиями).
- **Внутренний changelog** (версии 1.0 → 2.2) в README, согласованный с историей коммитов, — редкий для профиля svend4 случай, когда самоописание репозитория полностью совпадает с реальностью.
- **Ядро идеи «параллелей»** реализовано как контент: `06-классификации/01-классификация-по-количеству.md` сводит системы разных культур по числу элементов; перекрёстные упоминания (7 = радуга = дни недели = ноты) проходят через многие документы.

## Чего нет

- **Кода нет вообще** — при том что описание обещает «псевдо ии»: ни движка соответствий, ни поиска, ни структурированных данных (JSON/YAML/CSV) из текста не извлечено.
- **Лицензии нет** (LICENSE отсутствует, проверено — 404); есть лишь фраза «для образовательных и справочных целей», юридически это ничто.
- **Источников и ссылок на литературу нет ни в одном документе** — контент сгенерирован ИИ (14/16 коммитов от `claude`) и не фактчекнут; для базы «знаний» это главный риск.
- **CI/проверок нет**: ни линтера markdown, ни проверки битых ссылок (а ссылки-заглушки `#` на «будущие документы» уже есть).
- **Тестов нет** (для чистой документации это нормально, но проверку целостности ссылок/индекса можно было бы автоматизировать).
- **CONTRIBUTING/CLAUDE.md/.gitignore нет**; issues не используются (несмотря на приглашение в README «используйте Issues»).
- **Нет машиночитаемого слоя соответствий** — «параллели» существуют только как связный текст, их нельзя запросить программно.

## Плюсы

1. **Честная статистика**: заявленные «39 документов, 10 категорий» подтверждены на 100% — редкость среди самоописаний в этом профиле.
2. **Дисциплина структуры**: строгая нумерация, единый шаблон документов, двухуровневая навигация — корпус легко читать и легко обрабатывать программно.
3. **Широта охвата при связности**: от символики чисел до квантовых компьютеров, при этом документы ссылаются друг на друга по смысловым «параллелям».
4. **Видимый рост качества**: от 90-строчных ранних заметок до 900–1200-строчных поздних мини-учебников.
5. **Готовый корпус для NLP/RAG-экспериментов**: однородный, тематически размеченный самими именами папок русскоязычный текст — идеальное сырьё.

## Минусы

1. **Ни одного источника** — энциклопедические утверждения (даты, цифры заболеваемости, «86 млрд нейронов») не подкреплены ссылками; часть цифр заведомо требует проверки, доверять корпусу как справочнику нельзя без верификации.
2. **Обещание «псевдо ии» не реализовано** — репозиторий остановился на стадии «контент есть, механики нет».
3. **Кириллические имена файлов и папок** осложняют работу с URL (нужно percent-кодирование), некоторыми инструментами и кросс-платформенными сценариями.
4. **Однократный «спринт» без сопровождения**: вся жизнь репозитория — 3 дня в январе 2026; ссылки-заглушки на «будущие документы» повисли.
5. **Дубляж навигации**: структура репозитория описана и в README, и в ИНДЕКС.md — при любом изменении их нужно синхронизировать вручную (уже сейчас README-changelog занимает половину README).
6. **Нет лицензии** — формально контент нельзя легально переиспользовать, что противоречит образовательному назначению.

## Качество кода и документации

Кода нет — оценивается только документация. Markdown аккуратный и единообразный: иерархия заголовков соблюдена, списки консистентны, эмодзи-маркеры категорий используются системно, относительные ссылки корректны (кроме намеренных заглушек `#`). Стиль — «энциклопедическая выжимка»: плотные списки фактов без воды. Слабое место качества — не форма, а **верифицируемость**: ни цитат, ни источников, ни дат проверки фактов. README как витрина — выше среднего по профилю svend4.

## Зрелость: 3/5

Обоснование: контентная часть завершена и внутренне согласована (заявления = реальность), навигация работает, объём значительный — это больше, чем «эксперимент» (2/5). Но проекту не хватает лицензии, источников/фактчекинга, какой-либо автоматизации и главного — реализации заявленной идеи «псевдо ИИ» поверх корпуса; развитие остановилось через 3 дня после старта. До 4/5 не дотягивает именно из-за неверифицируемости контента и отсутствия механического слоя.

**Ограничение покрытия аудита**: из 39 документов целиком/фрагментами прочитаны 4 репрезентативных (числа 1–10, классификация по количеству, языки программирования, фрагменты README/ИНДЕКС); остальные проверены на существование, размер и соответствие аннотациям индекса, но не вычитывались построчно. Фактическая точность энциклопедических утверждений не проверялась — помечено как «не проверено».
