## Ключевые файлы и модули

| Файл | Что делает |
|---|---|
| `scarab_algorithm.py` | Монолит из 100 «версий» (v1–v100): ядро — `scarab_2d()` / `deformed_lissajous()` (генерация траекторий: запрет круга >4 шагов, запрет прямой >3 шагов, нечётные серии {1,3,5,7}, поворот π/4, отражение от границ, 4 вложенных уровня БВС/СВС/МВС/ЧВС с разными временными масштабами); далее классы `ScarabQuaternion`, `MatchStickAutomaton`, `DualMatchStickAutomaton` (двурукий «жонглёр»), тренировочная экосистема (`StudentProfile`, `KataLibrary`, `School`, `Federation`, `EloRating`, `SpacedRepetition`, `AdaptiveQuiz`, `Leaderboard` …) и с ~v60 — типовые инфраструктурные компоненты (EventStore, ORM, HTTPRouter, BTreeIndex, BloomFilter, CryptoHash, LoadBalancer, TaskDAG …). В `__main__` — 335 демо с assert. Зависимости: только `math` и `random` |
| `SESSION_Deformed_Figure8_Scarab_Algorithm.md` | Концептуальный «журнал сессии» (23.02.2026): вывод алгоритма Скарабея из деформированной восьмёрки Крюкова, размерностная иерархия циклов, роза ветров ↔ триграммы И-Цзин, алфавит движений на 76 символов, спецификация «спичечного автомата», методика тренировок |
| `SERIES_INDEX.md` | Полный аннотированный указатель томов 1–20 + таблица 12 архетипов с математикой |
| `SERIES_II_INDEX.md` | Указатель томов 21–40; **устарел** (тома 31–40 помечены «📋 план», хотя написаны; фактические темы 36–40 отличаются от заявленных) |
| `TSB_Annual_Training_Plan.md` | Годовой план тренировок ТСБ: формула «Тренировка n = nA+nB+nC», 4 квартала, ~144 тренировки/год, нотация записи |
| `VOLUME_100…102` | Робототехническое ядро корпуса: 4-сферная кинематическая модель (МВС=сустав, СВС=манипулятор, БВС=система, ЧВС=инструмент/задача как plug-in), LCI-формула с task_efficiency, идея Deep-RL-политики как ЧВС-слоя |
| `totalnaya_sistema_boya.pdf`, `Zelendinov_*.rtf/txt/zip` | Полные тексты чужих книг-первоисточников (потенциальная проблема авторских прав) |

## Особенности организации

- **Плоская структура**: 300+ файлов в корне, без каталогов — навигация возможна только по именам `VOLUME_NN_…`.
- **Индексы покрывают лишь 13% корпуса**: для томов 41–310 (270 файлов) указателей нет; ориентироваться можно только по сообщениям коммитов («Волна N: тома X–Y»).
- **Однофайловый код**: весь Python — один файл на 75 тыс. строк; версии отделены комментариями `# vNN: …`, в конце — приложения A–L (справочники, глоссарий, чек-листы) прямо в комментариях.
- **Двухверсионные тома**: после появления «четвёртой сферы» (ЧВС) часть ранних томов дописана до формата «ВЕРСИЯ 1.0 (3 сферы) / ВЕРСИЯ 2.0 (4 сферы)» (коммиты «параллельные v1.0+v2.0»).
- **Веб-листинг GitHub обрезается** примерно на 100 записях, из-за чего в интерфейсе «не видно» томов 36–99 и 176–310, а также самого `scarab_algorithm.py` — их существование подтверждено прямыми raw-запросами.

Ограничение покрытия аудита: из 310 томов подробно прочитаны ~10 (1–20 по индексу, 51, 100–103, 310, SESSION, TSB-план) плюс структурный анализ и полный прогон `scarab_algorithm.py`; остальные тома оценены по индексам, заголовкам и сообщениям коммитов.
