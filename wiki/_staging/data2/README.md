# data2 — корпус «Единой Теории Движения» (ЕТД) по Крюкову: 310 томов + Python-монолит «Алгоритм Скарабея»

## Обзор

`data2` — самый крупный контентный репозиторий профиля svend4: машинно-сгенерированный (Claude) книжный корпус из **310 «томов»** (VOLUME_01…VOLUME_310), развивающий «Единую Теорию Движения» (ЕТД) на основе книги В.В. Крюкова «Тотальная Система Боя» (ТСБ), плюс **один гигантский Python-файл** `scarab_algorithm.py` на **75 004 строки** (2,56 МБ) — «Алгоритм Скарабея», генератор управляемо-хаотичного движения для робототехники, обросший сотнями сервисных компонентов.

Важно: внешние листинги GitHub обманчивы. Веб-интерфейс показывает лишь часть файлов (обрыв на ~100 записях), а языковая статистика «Python 56,1% / Rich Text Format 43,9%» объясняется всего двумя файлами: `scarab_algorithm.py` (2,56 МБ) и RTF-книгой Зелендинова «Единый язык фехтования» (2,0 МБ) — markdown-тома GitHub в статистике не учитывает.

## Назначение и идея

Исходная идея: из книги Крюкова извлечены **12 «архетипов движения»** (петля, три вложенные сферы МВС/СВС/БВС, закон нечётности, закон памяти 7±2 и т.д.), формализованы математически (фигуры Лиссажу, LCI — Loop Closure Index, конечные автоматы) и затем **систематически применены ко всем областям знания**: геймдизайн, бытовая робототехника, ИИ/RL, медицина, педагогика, финансы, лингвистика, боевые искусства, а с тома 103 — «математические основания» (кватернионы, топология, теория категорий и ещё ~200 разделов математики, где везде «доказывается» роль числа 4 — четырёх сфер).

Практический слой — робототехника: тома 3, 100–102 описывают четырёхсферную кинематическую модель робота (МВС/СВС/БВС/ЧВС — сустав/манипулятор/система/инструмент-задача), а `scarab_algorithm.py` реализует генерацию непредсказуемых, но ограниченных траекторий (запрет прямой, запрет круга, нечётные серии, деформированная восьмёрка).

По характеру это **спекулятивно-творческий корпус** («вечная аналогия числа 4»), а не рецензируемая наука — «доказательства» в математических томах представляют собой подгонку совпадений вида `15 = N²−1 при N=4`.

## Как устроено (архитектура)

Три слоя:

1. **Исходники-первоисточники** — загруженные владельцем книги: `totalnaya_sistema_boya.pdf` (Крюков, 1,3 МБ), второй PDF (366 КБ), книга Зелендинова по фехтованию (RTF 2,0 МБ + TXT + 2 ZIP).
2. **Корпус томов** — 310 markdown-файлов, организованных в серии:
   - Серия I (тома 1–20): открытие 12 архетипов (индекс `SERIES_INDEX.md`);
   - Серия II (21–40): прикладная ЕТД (индекс `SERIES_II_INDEX.md`);
   - Серии III–V (41–80): математизация и «ЕТД во всех науках»;
   - Серия VI (81–97): боевые искусства;
   - Серия VII (98–102): первоисточники и робототехника (ЧВС — четвёртая сфера);
   - «Математические волны» 1–21 (тома 103–310): основания ЕТД по мотивам эссе Франца Германа «Четыре», каждая волна из 10 томов завершается «синтезом».
3. **Код и сессии** — `scarab_algorithm.py` (100 «версий» v1→v100, 227 классов, 425 функций, 335 демо с assert-ами, только stdlib) и `SESSION_Deformed_Figure8_Scarab_Algorithm.md` (26 890 строк концептуального анализа: роза ветров, алфавит движений из 76 символов, «спичечный автомат», годовой план тренировок — дублируется в `TSB_Annual_Training_Plan.md`).

## Статус и активность

- Вся история — **160 коммитов за 9 дней: 17–25 февраля 2026**. С 25.02.2026 активности нет (на момент аудита 02.07.2026 — 4+ месяца тишины).
- Работа велась связкой «владелец + Claude»: владелец загружал книги, Claude-ветки (`claude/analyze-movement-archetypes-jf1M2`, `claude/amazing-bell-rD9ov`) наполняли тома и код; 9 pull request'ов, все влиты.
- Проект выглядит **сознательно доведённым до вех**: том 310 = «Девятнадцатый синтез», scarab v100 = «юбилейная версия, 75K строк». Формально завершён, но продолжение явно возможно (волны шли до последнего дня).
- Перепроверка заявлений (аудит): «75 004 строки» — подтверждено точно; «0 ошибок, 335 демо» — файл выполнен целиком, exit 0, все assert прошли; «100 версий» — маркеры v1…v100 на месте; «275+ компонентов» — насчитано 227 классов верхнего уровня + 425 функций (правдоподобно, зависит от методики счёта). Расхождение найдено в `SERIES_II_INDEX.md`: тома 36–40 там значатся запланированными (📋) с темами «Сознание/Космология/…», фактически же написаны другие (36 — ИИ, 37 — квантовые вычисления, 38 — нейронаука) — индекс не обновлён.
