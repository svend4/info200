# infon — TVCP: видеосвязь в терминале + ray/Q6/alife-платформа генеративных миров

## Обзор

**infon** — самый крупный и зрелый инженерный проект профиля svend4. Под вывеской «TVCP — Terminal Video Communication Platform» скрывается фактически три сросшихся проекта в одном Go-монорепо:

1. **TVCP** — платформа видеозвонков *внутри текстового терминала*: видео рендерится Unicode-блоками (▀▄▌▐…) с 24-битным ANSI-цветом, аудио 16 кГц, P2P-сеть через Yggdrasil, заявленный трафик ~382 kbps («в 9 раз меньше Zoom»).
2. **Слой ИИ `tvcp-ai/1`** — открытый протокол (JSON over HTTP), позволяющий *любой* нейросети быть «мозгом» терминала: рисовать (draw-DSL, «псевдоизображения»), играть (крестики-нолики, Wordle, UNO), режиссировать миры. Адаптеры на Python для Anthropic (Claude Haiku проверялся вживую), Ollama и OpenAI-совместимых API.
3. **Ray/Q6/alife-платформа** — CPU-трассировщик путей (`pkg/raytrace`, включая BDPT, photon mapping, ReSTIR, PSSMLT), «мост смысла» гексаграмма И-Цзин ↔ 3D-мир (`SceneVector`, куб Q6 из 64 гексаграмм), искусственная жизнь (экосистемы, сезоны, климат), совместные обитаемые миры по UDP: несколько людей и ИИ-режиссёр ходят по одному растущему миру, а по проводу передаётся только «смысл» (~40× меньше байтов, чем пиксели — демонстрируется `cmd/raypipe`).

В репозитории **121 команда** в `cmd/` (есть автогенерируемый индекс `docs/COMMAND_INDEX.md`), ~46 пакетов в `pkg/`, 25 пакетов в `internal/`, обширные тесты (только в `pkg/raytrace` ~55–60 файлов `*_test.go`, в `pkg/raydir` — ещё ~55–70), CI на три ОС, MIT-лицензия, CHANGELOG и десятки документов.

## Назначение и идея

Исходная идея (зафиксирована в русскоязычном бизнес-плане `tvcp-business-plan.md`, февраль 2026, на основе проектов svanichkin/say и svanichkin/.babe): человеческий мозг узнаёт лицо и эмоции даже при «разрешении» 80×40, значит для базовой видеосвязи не нужны мегабиты — достаточно ~200 kbps при правильной кодировке. Три столпа: блочный кодек `.babe` (2×2 субпикселя, 2 цвета на блок), mesh-сеть Yggdrasil (без серверов и аккаунтов, E2E-шифрование), терминальный рендеринг (квадранты + TrueColor). Целевые сценарии: DevOps/SSH, IoT-мониторинг, спутниковый интернет, приватность, тактическая связь.

Затем проект эволюционировал в более общий тезис — **«передавать смысл, а не пиксели»**: вместо видеопотока по сети идут крошечные описания сцены (`SceneSpec`, ~100 байт на регион, позы по 44 байта), а картинку каждая машина рендерит локально своим трассировщиком. На этом тезисе выросла целая платформа: ИИ-режиссёр миров, обратный «читатель» (изображение → гексаграмма + настроение), атлас всех 64 миров, соноификация (мир как музыка), обучающиеся агенты в лабиринте на гиперкубе Q6, куратор по «вкусу» зрителя.

## Как устроено (архитектура)

- **`cmd/`** — 121 самостоятельная команда: главный бинарь `tvcp` (call/send/receive/chat/share/group/avatar/synth…), семейства `ai*` (игры и рисование через мозг), `arena*` (тангram-сражения с ИИ-командирами и трансляцией по каналу с потерями), `ray*` (~45 команд: rayexplore, raymeet, raytour, raylife, raydungeon, raysound, raypipe…), `sem*` (семантический видеокодек).
- **`pkg/`** — переиспользуемые «вещества»: `raytrace` (рендер-движок), `raydir` (Q6, миры, экосистемы, ~740 публичных символов по заявлению CONCEPT_MAP — не перепроверено), `brain` (протокол tvcp-ai/1 + референсный мозг), `scene`/`sketch`/`pseudo` (рисование для текстовых моделей), `semvideo`/`deltastream`/`dtn` (семантическое видео, дельты, delay-tolerant networking), `glyphqr`, `tangram7`, `arecibo`/`lincos` и др.
- **`internal/`** — медиа-ядро TVCP: `audio` (ALSA/CoreAudio/WASAPI), `video`, `codec` (.babe), `network`, `sfu`, `yggdrasil`, `avatar` (нейроаватар ~35 kbps), `vision`, `recorder`, `screen` и т.д.
- **`ai/`** — спецификации протокола (BRAIN_PROTOCOL.md, SPEC.md, schema), Python-адаптеры (anthropic/ollama/openai + сайдкары vision/restore/avatar), витрина showcase.html.
- **`experimental/`** — функции под build-тегом `experimental`: игры, whiteboard, breakout-комнаты, fileshare + собственные обзорные документы.
- **`mobile/`, `web/`, `scenes/`, `scripts/`** — Kotlin/Swift-заготовки, HTML-игрушка tangramcraft, сцены, генератор индекса команд и smoke-скрипт `qa.sh`.
- **`nautilus.json`** — манифест федерации «nautilus/1»: infon объявляет себя «renderer-узлом Q6-федерации» и ссылается на репозитории meta (математика), pro2 (модель) и info150 (системы); интероп описан в `docs/Q6_INTEROP.md`.

Зависимости минимальны: в `go.mod` только ALSA-байндинг и Opus — весь рендер, кодеки и сеть написаны с нуля.

## Статус и активность

- **455 коммитов**, ветка `main`, последняя активность **11 июня 2026** (merge PR #16 — серия «блоков A–L» ray/Q6/alife плюс документы CONCEPT_MAP/COMMANDS/COMMAND_INDEX); репозиторий обновлён 2026-06-15. Разработка ведётся через PR-ветки `claude/...` (совместно с Claude Code).
- CI (`.github/workflows/ci.yml`): матрица ubuntu/macos/windows × Go 1.21/1.22, `go vet`, тесты с `-race` и покрытием (таймаут 30 мин из-за Монте-Карло-тестов несмещённости трассировщика), сборка бинаря. Есть `release.yml` и вдумчиво прокомментированный `.golangci.yml`.
- Версия ядра TVCP — **0.0.1-alpha** («Alpha MVP» в бейдже README); ray/Q6-платформа при этом плотно покрыта тестами.
- Самоаудиты в репо: `experimental/DOCUMENTATION_REVIEW.md` (ревью документации по играм), `docs/cross-pollination-analysis.md` (TVCP × Doom-over-DNS), упоминание «аудита спящего кода» (команда `rayfx` активирует протестированные, но не подключённые рендереры). Перепроверка: заявленные «121 команда» и массовые тесты подтверждаются деревом репозитория; цифры пропускной способности (382 kbps, 9× vs Zoom) и «байт-в-байт совпадение Go/Python» — не перепроверены.
