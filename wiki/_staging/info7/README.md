# info7 — TypeScript-монорепо «AI-платформы»: оркестратор агентов, граф знаний, самообучающийся ИИ и enterprise-агенты

## Обзор

**info7** — самый крупный по объёму кода репозиторий из «оркестраторной» линейки профиля svend4: TypeScript-монорепозиторий из 5 пакетов (~31,5 тыс. строк кода в ~94 файлах) плюс ~38 markdown-документов в корне. Репозиторий позиционирует себя как «Production-Ready AI Platform» с завершённостью «99.5%» (бейджи в README), однако весь проект был создан за **три дня** (5–7 февраля 2026, 101 коммит, автор большинства коммитов — «Claude») и с тех пор не обновлялся. Аудит-перепроверка показала: объём кода заявлен честно, но заявления о «production ready» и «tested» реальности **не соответствуют** — в репозитории **ноль тестовых файлов**, сборка сломана как минимум в двух местах, а «семантический поиск» в графе знаний реализован заглушкой на кодах символов.

## Назначение и идея

Идея проекта — интегрированная ИИ-платформа из четырёх систем (плюс общий пакет утилит):

1. **@info7/openclaw-meta-agents** — иерархическая оркестрация агентов: 5-уровневая иерархия (Meta-Meta-Agent → Meta-Agent → Coordinator → Specialized → Worker/Executor), декомпозиция задач, выбор агентов, 5 стратегий координации (Sequential, Parallel, Pipeline, Hierarchical, Collaborative) и 3 специализированных агента (Legal, Medical, Finance).
2. **@info7/info7** — «активная база знаний»: семантический граф знаний с 9 типами узлов и 12 типами связей, поиск, аналитика графа, автообновление из 6 типов источников.
3. **@info7/leonardo-ai** — «самообучающийся ИИ» (это и есть «л аи» из описания репозитория — Leonardo AI): RL-движок на TensorFlow.js (policy/value-сети, experience buffer), RAG-движок (OpenAI embeddings + Pinecone), мета-обучение (5 стратегий, вкл. MAML и few-shot), «Consciousness Layer» (самоанализ и объяснение решений) и «Corpus Callosum» (двусторонняя синхронизация RAG ↔ граф знаний).
4. **@info7/orchestrator-kit-enterprise** — enterprise-слой: мультиарендность (TenantManager/UserManager), RBAC, аудит-лог и **10 «профессиональных агентов»** в 8 доменах (юрист по контрактам, иммиграционный специалист, калькулятор соцпособий, медицинская диагностика, ментальное здоровье, инвестиционный советник, карьерный консультант, домашний менеджер, уход за пожилыми, нутрициолог).
5. **@info7/common** — общие утилиты: логгер (winston), конфиг-менеджер, ошибки, валидация (zod), health-check, метрики.

Отдельно лежит **openclaw-security/** — «инициатива безопасности OpenClaw»: отчёт о «230+ вредоносных скиллах» в экосистеме OpenClaw и пакет @openclaw/sandbox для изолированного исполнения скиллов (на базе vm2).

По сути это концепт-прототип «всё-в-одном» ИИ-платформы, сгенерированный в интенсивной сессии с Claude: архитектура и типизация продуманы, но интеграции с реальным LLM нет — «агенты» принимают решения по захардкоженным правилам (if/else и таблицы знаний), а обучение и «сознание» — это симуляции внутри процесса.

## Как устроено (архитектура)

- **Монорепо**: корневой `package.json` (npm workspaces) + `pnpm-workspace.yaml`; workspace-глоб `packages/*`. Общий `tsconfig.json` (strict, ES2020, composite).
- Каждый пакет: `src/` с модулями по папкам, `index.ts` с реэкспортами, обширные example-файлы (~5,7 тыс. строк из 31,5 тыс. — примеры/демо).
- Зависимости между пакетами через `@info7/common` (`workspace:*` — протокол pnpm, **не поддерживаемый npm**, при том что README велит `npm install`).
- Реальные внешние зависимости заявлены только в leonardo-ai: `@tensorflow/tfjs-node`, `openai`, `@pinecone-database/pinecone`; в enterprise — `passport`, `bcrypt`, `jsonwebtoken` (в коде фактически не задействованы — auth-логика самописная, in-memory).
- Всё состояние хранится в `Map` в памяти процесса; персистентности (БД, файлы) нет — только JSON import/export, описанный в `IMPORT_EXPORT_GUIDE.md`.

Критические дефекты сборки, найденные при перепроверке:
- `packages/info7/` **не имеет `package.json` и `tsconfig.json`** — пакет «база знаний» не является валидным workspace-пакетом и не собирается; в корневых скриптах нет `build:info7`/`test:info7`.
- `packages/leonardo-ai/src/index.ts` экспортирует `runExample` из `./example` — **файла `src/example.ts` не существует** (есть только `src/rl/example.ts`), значит `tsc` этого пакета падает.
- Тестов нет ни одного файла (`*.test.ts` — 0 шт.), при этом vitest сконфигурирован, а документы утверждают «complete and tested».

## Статус и активность

- Создан и полностью написан **5–7 февраля 2026** (CHANGELOG: v0.1.0 от 2026-02-05 до v1.6.0/1.33.0 от 2026-02-07; иногда по релизу в час).
- **101 коммит**, почти все от 2026-02-07, автор большинства — «Claude»; один merge PR от svend4 (русский README).
- С 7 февраля 2026 активности нет (на дату аудита 2026-07-02 — ~5 месяцев тишины). Issues: 0, PR: 0, звёзд: 1.
- Внутренние самоотчёты противоречат друг другу: README — «27k+ LOC, 99.5%», `FINAL_STATUS.md` — «~31 000+ LOC, 100%, PRODUCTION READY», `SYSTEM_AUDIT.md` — «92%, ~25 000+ LOC». Фактический замер аудита: **~31,6 тыс. строк** (с комментариями и пустыми строками), т.е. цифры LOC близки к правде, а вот статусы «production ready / tested» — нет.
