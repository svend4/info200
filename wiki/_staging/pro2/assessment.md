## Чего нет

- **Файла LICENSE** — при заявленной MIT. Юридически лицензия не оформлена.
- **CI/CD** — нет `.github/workflows`; ~2000 тестов никогда не гоняются автоматически. Для проекта такого размера это главный операционный пробел.
- **Публикации пакета** (PyPI) и GitHub Releases — установка только `pip install -e .` из клона.
- **Бенчмарков на реальных масштабах** — самоаудит признаёт: всё на d=128, 800–1000 шагов, <100 K токенов; WikiText-103/OpenWebText прогонов нет.
- **Управления бинарными артефактами** — .pt-файлы в git вместо LFS/releases; репозиторий тяжёлый для клонирования.
- **Хорошей гигиены README** — два склеенных README с дублями и расхождениями.
- **CLAUDE.md** — при том что разработка явно ведётся через Claude (ветки `claude/*`).
- Внешних пользователей/сообщества: 1 звезда, 0 форков, contributors — один.

## Плюсы

1. **Редкая для профиля глубина**: не «info-заметки», а полноценный исследовательский ML-фреймворк с моделями, обучением, инференсом, квантизаторами, LoRA, speculative decoding, ONNX-экспортом.
2. **Тестовая культура**: ~2000 тестов, включая edge cases (batch=1, seq=1), fp16/bf16, device transfer — исключительно для «домашнего» исследовательского кода.
3. **Самокритичная документация**: THEORY_VS_PRACTICE, IMPLEMENTATION_STATUS с колонкой «в бою», зафиксированные баги и их фиксы (interlingua_fixed) — воспроизводимый исследовательский процесс.
4. **Оригинальная научная идея** с проверяемым математическим ядром (Q6-изоморфизм — факт; факторизация 64=8×8 — факт) и корректным бейзлайном (VanillaGPT).
5. **Зафиксированная эволюция v53–v69** с PPL-таблицами: видно, что не работало (v60–v61) и почему.

## Минусы

1. **Toy-scale результаты подаются броско**: «PPL 1.24» на синтетическом корпусе <100 K токенов ничего не говорит о применимости; заявление «LCI сходится к π как аттрактору» — экстраординарное и не верифицированное независимо.
2. **Нет CI** — при ~2000 тестов регрессии ловятся только вручную.
3. **Разрастание без прополки**: 24 скрипта в корне, 45+ JSON-логов, utils_v12–v52, двойной README — высокая когнитивная нагрузка на входе.
4. **Лицензионная неопределённость** (нет LICENSE) блокирует любое внешнее использование.
5. **Бинарные чекпоинты в git** раздувают историю.
6. **Bus-фактор = 1**, внешней валидации идей нет (нет статьи, препринта, обсуждений).

## Качество кода и документации

Код (по прочитанным фрагментам `core.py`, `pipeline.py`, `setup.py`): аккуратный, с русскими докстрингами, тайп-хинтами, осмысленными комментариями (вплоть до фикса зависания BLAS через `OMP_NUM_THREADS=1`). Документация обширна и необычно честна, но частично рассинхронизирована между версиями (двойной README, списки тестовых файлов марта vs апрель). Русско-английская смесь терминологии последовательна.

## Зрелость: 3/5

**Обоснование:** масштабная работающая кодовая база с пакетированием, ~2000 тестами, чекпоинтами и выдающейся документацией — это уверенно выше среднего (2). До 4/5 не дотягивает из-за: отсутствия CI и LICENSE, toy-scale валидации ключевых научных заявлений, отсутствия релизов/PyPI, бинарников в git и bus-фактора 1. Статус «Advanced Alpha», указанный самим проектом, точен.
