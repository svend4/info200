Проект достиг развилки: 90 K строк, 11 моделей, v69 экспериментов — дальше вкладываться «во всё сразу» дорого.

**Варианты ответов:**
- А. Научная цель — доказать пользу Q6-смещения и опубликовать.
- Б. Инженерная цель — микро-модели/семантический индекс для остальных репо профиля.
- В. Это исследовательская лаборатория ради процесса; конечной цели нет.

**Варианты дальнейших действий:**
- При А: заморозить новые архитектуры, сценарий «Научная валидация» (WikiText-103-бенчмарк, проверка LCI→π, препринт из paper_draft.md).
- При Б: сценарий «Семантическое ядро»: довести nautilus-адаптеры, упаковать инференс NautilusMoME как утилиту, интегрировать с info200/lorenzo.
- При В: минимальная гигиена (LICENSE, CI, один README), дальше — свободный полёт; но зафиксировать в шапке README, что это лаборатория, чтобы читатель калибровал ожидания.

## 5. Планируется ли слияние/синхронизация встроенного nautilus/ с отдельным репозиторием nautilus профиля?

**Варианты ответов:**
- А. Каноническая версия — в pro2, репо nautilus — витрина/протокол.
- Б. Каноническая — отдельный репо nautilus, в pro2 копия и она устареет.
- В. Они уже синхронизируются (federated_round.py / вручную).

**Варианты дальнейших действий:**
- При А: в README репо nautilus поставить ссылку «код живёт в pro2/nautilus», чтобы не поддерживать две версии.
- При Б: удалить копию из pro2, подключать как сабмодуль или зависимость.
- При В: задокументировать процедуру синхронизации в docs/PORTAL.md — сейчас её из репозитория не видно.
