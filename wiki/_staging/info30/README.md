# info30 — «Claude Code Knowledge System»: файловая база знаний (инструкции, агенты, скиллы) для Claude Code

## Обзор

**info30** — это чисто документационный репозиторий, содержащий каркас «RAG-подобной» системы знаний для Claude Code. Вся полезная нагрузка лежит в скрытой папке `.claude-knowledge/`: главная документация, quick-start, по одному эталонному примеру инструкции (настройка Docker), агента (code-reviewer в YAML), скилла (smart-refactor), пять сценариев использования и два методологических руководства (форматы хранения знаний и интеграция с MCP). Исполняемого кода в репозитории нет — только Markdown и один YAML.

Репозиторий создан 9 февраля 2026 года по сути одним содержательным коммитом (`feat: implement comprehensive Claude Code knowledge system with RAG...`, автор — claude), который был влит через PR #1 18 апреля 2026 года. Всего 3 коммита, 1 звезда, 0 форков.

## Назначение и идея

Идея проекта: «не всё должно быть встроено в нейросеть» — дополнительные знания, инструкции, конфигурации агентов и скиллов хранятся в структурированных текстовых файлах рядом с проектом, а Claude Code читает их по требованию (напрямую, через memory-файлы или через MCP-сервер `@modelcontextprotocol/server-filesystem`). Заявленные типы знаний: инструкции, агенты, скиллы, шаблоны, примеры, интеграции, документация — каждому отведена своя ветка каталога с соглашениями о формате (Markdown с YAML frontmatter для инструкций/скиллов, YAML для агентов, JSON для данных).

Фактически репозиторий — это **спецификация и демонстрационный образец** такой системы: по одному тщательно оформленному примеру на категорию плюс подробная методология, а не наполненная рабочая база знаний.

## Как устроено (архитектура)

- **Корень**: единственный файл `README.md` (412 строк, витрина проекта на русском) и папка `.claude-knowledge/`.
- **`.claude-knowledge/README.md`** (512 строк) — главная документация: принципы, полная целевая схема каталогов, стандарты форматирования для инструкций/агентов/скиллов.
- **`.claude-knowledge/QUICK-START.md`** (457 строк) — быстрый старт за 15 минут.
- **Примеры-эталоны** (по одному на категорию):
  - `instructions/deployment/docker-setup.md` (536 строк) — пошаговая инструкция с богатым YAML frontmatter (difficulty, duration, success_criteria, related_files);
  - `agents/custom-agents/code-reviewer.yml` (545 строк) — декларативная конфигурация агента: параметры с валидацией, инструменты, внешние линтеры, системные промпты;
  - `skills/custom-skills/smart-refactor.md` (521 строка) — скилл `/refactor` с параметрами и шаблонным промптом;
  - `examples/use-cases/real-world-scenarios.md` (830 строк) — 5 сценариев (онбординг, стандартизация кода, авто-review, документирование legacy, миграция стека).
- **Методология**: `documentation/methodology/knowledge-formats.md` (1325 строк — самый большой файл, сравнение Markdown/YAML/JSON/кода/гибридов) и `documentation/guides/mcp-integration.md` (794 строки — настройка MCP, ASCII-диаграмма архитектуры, создание кастомных серверов).

Важно: заявленные в документации ветки `templates/`, `integrations/`, `instructions/coding|architecture|testing|best-practices` и др. **в git отсутствуют** — реально существует только 9 файлов (подробности в [assessment.md](assessment.md)).
