# Вопросы к daten20

## 1. Что является целевым продуктом: планировщик услуг персонального бюджета или AI-платформа?

Ядро (mSchablone, финансовый калькулятор с немецкими ставками) и надстройка (BCI, quantum ML, consciousness, the_void) — принципиально разные проекты с разными аудиториями, склеенные в один репозиторий.

**Варианты ответов:**
- А. Продукт — планировщик соцуслуг; AI-слои были экспериментом.
- Б. Продукт — универсальная AI-платформа; соцуслуги были лишь первым кейсом.
- В. Осознанного продукта нет — это полигон ИИ-ассистированной разработки.

**Варианты дальнейших действий:**
- При А: выполнить Сценарий 1 из рекомендаций — вынести ядро в отдельный чистый репозиторий, AI-слои заархивировать; README переписать под соцсектор.
- При Б: провести инвентаризацию 70 модулей src/, удалить имитационные (v25–v30), для остальных написать честную матрицу «работает/имитация», иначе платформе никто не поверит.
- При В: выполнить Сценарий 2 или 4 — оформить как исследовательский кейс либо честно законсервировать.

## 2. Сколько тестов реально проходит, если запустить весь `tests/`, а не только `tests/test_doc_*.py`?

CI-workflow `tests.yml` гоняет только подмножество `test_doc_*.py`; заявления «284/284» и «2 030+ тестов» независимо не подтверждены, а три самоотчёта называют три разных числа (172, 284, 2030+).

**Варианты ответов:**
- А. Полный прогон проходит — просто CI настроен на быстрое подмножество.
- Б. Полный прогон частично падает (особенно AI-модули v21–30).
- В. Полный прогон никогда не выполнялся целиком.

**Варианты дальнейших действий:**
- При А: добавить в CI ночной workflow с полным прогоном и вписать реальное число в README — это сразу снимет главное недоверие к проекту.
- При Б: пометить падающие тесты `xfail` с причинами, вынести нестабильные модули из «production»-заявлений.
- При В: провести полный локальный прогон один раз, зафиксировать результат в новом (единственном) STATUS-документе; старые самоотчёты перенести в docs/archive/.

## 3. Почему в репозитории нет файла LICENSE при MIT-бейдже в README?

Проверено: LICENSE, LICENSE.md, LICENSE.txt, COPYING — все 404. Без лицензии код формально «all rights reserved», и никто не вправе его использовать.

**Варианты ответов:**
- А. Забыли добавить — намерение MIT.
- Б. Лицензия сознательно не выбрана (проект личный).

**Варианты дальнейших действий:**
- При А: добавить LICENSE (MIT) одним коммитом — 5 минут.
- При Б: убрать MIT-бейдж из README и явно написать «proprietary/личный проект», чтобы не вводить в заблуждение.
