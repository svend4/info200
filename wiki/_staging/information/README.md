# information — пустой репозиторий-«входящие» для новостных закладок через GitHub Issues

## Обзор

`information` (описание на GitHub: «info новости ньюз») — практически пустой репозиторий: в нём ровно **один коммит** («Initial commit», 11 марта 2026) и **один файл** — `README.md` из двух строк (`# information` / `info`). Ни кода, ни документации, ни конфигурации в дереве файлов нет.

Однако репозиторий не совсем «мёртвый»: вся его фактическая функция вынесена **в GitHub Issues**. На момент аудита открыты 3 issue (все созданы 11 марта 2026, в день создания репозитория), и каждый из них — это закладка на внешнюю новость/статью:

1. **Issue #1** — «Künstliche Intelligenz für TVöD / TV-L. Haufe CoPilot HR öD…» — ссылка на немецкий ИИ-ассистент по кадровым вопросам госслужбы (shop.haufe.de/copilot-hr-oed).
2. **Issue #2** — «Акции китайских IT-гигантов взлетели на фоне „разведения лобстеров“ / Хабр» — ссылка на новость Хабра (habr.com/ru/news/1008838/).
3. **Issue #3** — «Виды моделирования данных. Полный гайд» — ссылка на статью Хабра (habr.com/ru/articles/1008204/).

Тело каждого issue — только URL, без аннотаций, тегов (labels), комментариев и какой-либо обработки.

## Назначение и идея

Судя по описанию («info новости ньюз») и содержимому issues, репозиторий задуман как **личный новостной инбокс / коллектор закладок**: владелец сохраняет интересные статьи в виде issues (заголовок статьи = заголовок issue, тело = ссылка). Это известный лёгкий паттерн «GitHub Issues как read-it-later»: бесплатно, с поиском, метками и API, доступно с телефона.

Тематика сохранённых ссылок разнородна: ИИ-продукты для HR в немецком госсекторе, финансовые новости китайского IT, методология моделирования данных — то есть это именно «входящие» без рубрикации, а не тематическая подборка.

## Как устроено (архитектура)

Архитектуры как таковой нет:

- **Git-дерево**: единственный файл `README.md` (2 строки), одна ветка `main`, 1 коммит.
- **Слой данных**: GitHub Issues — 3 открытых issue-закладки, все без labels, milestones, assignee и комментариев.
- **Автоматизация**: отсутствует — нет GitHub Actions, нет скриптов сбора/дайджеста, нет шаблонов issue (`.github/ISSUE_TEMPLATE`).

Иными словами, «информационная система» здесь — это ручное использование стандартного интерфейса GitHub Issues поверх пустого репозитория.
