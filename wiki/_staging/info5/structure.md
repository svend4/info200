## Ключевые файлы и их роль

| Файл | Что делает / содержит |
|------|----------------------|
| `README.md` | Точка входа: концепция, ASCII-пирамида, заявленные цифры (5000+ приложений, 200–300 кластеров, ROI 20–50x), статус Phase 0, навигация |
| `docs/methodology/level-3-clustering.md` | **Ядро №1**: как свернуть 5000+ приложений в 200–300 кластеров; многомерная классификация на базе NAICS/BPMN |
| `docs/methodology/level-2-mini-agents.md` | **Ядро №2**: что такое мини-агент, YAML-спецификация профиля (ответственность, знания приложений, use cases, best practices, метрики) |
| `docs/architecture/overall-architecture.md` | Системный дизайн: паттерны Single/Sequential/Orchestrated, потоки данных вверх/вниз, обработка ошибок (единственные фрагменты Python-псевдокода в репо) |
| `levels/level-2-agents-examples.md` | Крупнейший документ (1004 строки): «паспорта» конкретных агентов с процентами экспертизы и пошаговыми YAML-сценариями |
| `examples/use-cases.md` | Продающие сценарии «до/после» с расчётами экономии времени |
| `docs/ROADMAP.md` | План Q1 2026 → 2028+; полезен для аудита: обещания на февраль–март 2026 не выполнены |
| `docs/COMPARISON.md` | Позиционирование против Zapier/Make, ChatGPT, RPA, AutoGPT/LangChain |
| `LICENSE` | Необычная тройная схема: MIT сейчас + CC BY 4.0 для доков + расписанные лицензии будущих компонентов |

## Особенности организации

1. **«Книжная» структура вместо кодовой.** Репозиторий устроен как мини-сайт документации: оглавления, перекрёстные ссылки (абсолютные пути вида `/docs/...`, которые корректно работают только на GitHub), эмодзи-навигация.
2. **Полный «каркас» open-source-проекта без самого проекта**: CONTRIBUTING, 4 шаблона Issues, шаблон PR, двойная лицензия — при нуле реальных issues и контрибьюторов.
3. **Псевдокод как иллюстрация.** Немногочисленные вставки Python/YAML (`TaskDelegation`, `ClusterQuery`, `ErrorHandlingStrategy`, профили MA-агентов) — это спецификации-иллюстрации, а не исполняемый код.
4. **Единый момент создания.** Все файлы датированы «2026-01-28, версия 1.0»; 5 из 6 коммитов сделаны Claude в рамках одного PR — типичный результат одной генеративной сессии.
5. **Дублирование навигации**: корневой README и `docs/README.md` во многом повторяют друг друга (оглавление, статусные таблицы, roadmap-выжимка) и уже содержат расхождения (лицензия «TBD» против существующего LICENSE).
