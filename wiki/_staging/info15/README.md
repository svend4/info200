# info15 — вики-база знаний по YouTube-каналу @yersham

## Обзор

info15 — репозиторий с чисто документальным содержимым: двухверсионная markdown-вики («база знаний» в духе LLM Knowledge Bases Андрея Карпати), систематизирующая контент YouTube-канала @yersham — русскоязычного канала из Казахстана об ИИ, ИТ, биологии и медицине (по данным самой вики: канал создан в 2009, ~2661 видео, ~4710 подписчиков — цифры внешние, не проверены). Кода в репозитории нет: 37 markdown-файлов, ~3650 строк, ~223 КБ текста, всё на русском языке.

Вики состоит из двух каталогов:

- **`yersham_wiki/`** (v1, 28 файлов, ~3450 строк) — тематические статьи (AGI, агенты, Claude/Anthropic, context engineering, SDD, сознание ИИ, математика, биология и т.д.), детальные разборы ключевых видео и 6 тематических каталогов видео с оценками важности (★). Всего в вики ~194 уникальные ссылки на видео (youtu.be).
- **`yersham_wiki_v2/`** (v2, 8 файлов, ~190 строк) — «практический слой»: agentic-методы (Planner→Executor→Verifier, dual-loop), playbooks внедрения 30/60/90 дней, риски/governance, стек инструментов 2026. Явно заявлено, что v2 не заменяет v1, а дополняет её.

## Назначение и идея

Идея — превратить хаотичный поток видео канала (2+ видео в день в 2026) в структурированную, перекрёстно связанную энциклопедию, пригодную для чтения и человеком, и ИИ-агентом. Вики построена по описанной в ней же самой архитектуре Карпати (файл `13-video-deep-dives.md`): markdown-статьи вместо векторной БД, явные `[[wiki-ссылки]]` между концептами, `CLAUDE.md` с правилами обновления для агента. Репозиторий одновременно является и базой знаний, и демонстрацией метода, который эта база знаний описывает — вики о «LLM Knowledge Bases», сама сделанная как LLM Knowledge Base.

Судя по истории коммитов, весь контент создан ИИ-агентами (ветки `claude/research-ai-innovations-*` и `codex/analyze-youtube-channel-*`, 5 merged pull request'ов) за один день — 11 апреля 2026.

## Как устроено (архитектура)

- Корневой `README.md` — заглушка из 2 строк («# info15 / info»); реальная навигация — в `yersham_wiki/README.md`.
- **v1**: `README.md` (навигация + хронология канала) → тематические статьи `00–14`, `16–19` → сводка инноваций `20-innovations-2026.md` → 6 каталогов видео `20–25-catalog-*.md` (таблицы «название | youtu.be/ID | ★-важность | описание»). Каждая статья начинается блоком `> Связи: [[...]]`. Правила ведения — в `CLAUDE.md` (формат записей, пометки ⚠️ для нереализованных идей, карта связей).
- **v2**: 7 коротких статей + README; ссылается на страницы v1 (`[[13-video-deep-dives]]` и др.) как на точки встраивания.
- Внутренние `[[ссылки]]` v1 полностью резолвятся (проверено скриптом); ссылки из v2 в v1 работают только при открытии обеих папок одним Obsidian-vault.

Заявленный в `CLAUDE.md` слой `raw/` (исходные данные) в репозитории **отсутствует** — есть только «скомпилированная» вики без исходников.

## Статус и активность

Вся история — 12 коммитов за один день, 11 апреля 2026 (Initial commit + 5 merged PR от агентов claude/codex). С тех пор изменений нет, несмотря на то что `CLAUDE.md` описывает регламент постоянного обновления, а сам канал публикует 2+ видео в день. Фактически это **замороженный снапшот** исследовательской сессии одного дня. Issues — 0, releases — нет, ветка одна (main), звёзд/форков нет.
