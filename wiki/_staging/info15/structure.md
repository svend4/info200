## Особенности организации

- **Двухуровневая вики-конвенция**: каждая статья начинается с блока `> Связи: [[файл]] ...`; связи двунаправленно покрывают весь корпус. Проверка скриптом: все `[[ссылки]]` внутри v1 резолвятся (кроме двух шаблонных примеров в CLAUDE.md); v2 ссылается на 3 страницы v1 — на GitHub такие ссылки не кликаются, работают только в общем Obsidian-vault.
- **Само-референтная архитектура**: вики построена по методу, который описывает (LLM Knowledge Base Карпати), но реализует его неполно — слой `raw/` с исходниками отсутствует, «компиляция» невоспроизводима.
- **Следы мультиагентной сборки**: контент собран из PR веток `claude/...` и `codex/...`; отсюда дубли в `yersham_wiki_v2/README.md`, коллизия нумерации `20-*` и дыра `15-*`.
- **Версионирование каталогами**, а не git-историей: v2 — отдельная папка «расширение», а не эволюция v1.
