# Характеристика и оценка daten11

Аудит-перепроверка проведена 03.07.2026 по содержимому дефолтной ветки (8 коммитов от 30.12.2025). Прочитаны полностью: README.md, все файлы tools/, web/app.py, web/tools/search.py, scripts/auto_metadata.sh, render.yaml, Procfile, runtime.txt, requirements.txt, QUICKSTART_RENDER.md, схемы, примеры; частично (заголовки и первые ~100 строк): docs/METHODOLOGY.md, docs/AI_AUTOMATION.md, web/templates/index.html, web/static/js/main.js. Ограничение покрытия: 4 больших руководства в docs/ (~2700 строк) и main.css прочитаны выборочно; запуск кода в рантайме не производился — выводы о падениях сделаны статическим анализом однозначных случаев.

## Что есть

- **Целостная методология**: 4-уровневая модель метаданных внятно описана в README и docs/METHODOLOGY.md; соглашения об именах файлов (`.folder-meta.json`, `*.meta.json`, `*.summary.md`, `*.toc.md`) последовательно применяются во всех инструментах и примере.
- **Две формальные JSON Schema** (draft-07) для метаданных папок и файлов — редкость для проектов этого профиля.
- **Рабочий CLI-менеджер метаданных** (`tools/metadata_manager.py`): создание/чтение/обновление метаданных, статистика папок, контрольные суммы MD5/SHA256, MIME-типы. По коду — работоспособен на stdlib, без зависимостей.
- **Краулер** с генерацией JSON- и симпатичного HTML-отчёта о покрытии коллекции метаданными.
- **Полноценный по объёму веб-интерфейс**: Flask API (~9 эндпоинтов) + SPA на ванильном JS (645 строк) + продуманный CSS (994 строки, темы). Навигация по папкам (/api/folders, /api/folder) и статистика по коду должны работать.
- **Готовая инфраструктура деплоя**: render.yaml (Blueprint), Procfile, runtime.txt, healthcheck — деплой на Render в один клик действительно подготовлен.
- **Демо-данные**: examples/sample_library с полным комплектом метаданных для одного документа.
- **6 подробных руководств** (~3800 строк) — по объёму документации проект выделяется на фоне соседних репозиториев профиля.

## Чего нет

- **Тестов** — ни одного (ни unit, ни интеграционных). Именно поэтому баги ниже дожили до main.
- **CI/CD** — нет .github/workflows, ни линтера, ни проверки схем.
- **Файла LICENSE** — README заявляет «MIT», но `LICENSE` в корне отсутствует (проверено: 404 на raw). Формально код без лицензии.
- **Упаковки** — нет pyproject.toml/setup.py; не pip-устанавливается, отсюда дубликат search.py и sys.path-хаки.
- **Валидации по схемам** — schemas/ декларативны, ни один инструмент не проверяет метаданные по ним (jsonschema нет и в requirements).
- **Реализации заявленных расширений** — AI-генерация, Elasticsearch/Meilisearch, граф знаний существуют только в документации.
- **Актуальной инструкции деплоя** — QUICKSTART_RENDER.md велит выбирать ветку `claude/add-file-metadata-support-93MCI`, которой после мержа PR не существует.

## Найденные дефекты (по фактическому коду)

1. **Критический, `tools/search.py` и его копия `web/tools/search.py`**: `build_index()` использует `os.walk`, но `import os` есть только внутри `main()` и в блоке `if __name__ == "__main__"`. При запуске как скрипт CLI работает (import в `__main__` выполняется на уровне модуля), но при импорте из `web/app.py` модуль не получает `os` → `NameError` в /api/search и /api/facets. Веб-поиск неработоспособен.
2. **`tools/search.py`, `print_results()`**: в цикле по файлам печатается `folder.get('_path', '')` — переменная из предыдущего цикла по папкам; при пустом списке папок — `NameError`, иначе у всех файлов выводится путь последней папки.
3. **`tools/crawler.py`, `_process_file()`**: условие `file.suffix == '.meta.json'` никогда не выполняется (`Path('x.meta.json').suffix` == `'.json'`), поэтому `*.meta.json` учитываются как обычные файлы в отчётах.
4. **`scripts/auto_metadata.sh`**: вызывает `python3 ../tools/metadata_manager.py` относительно текущей директории; пример из README (`./scripts/auto_metadata.sh ./my_folder --recursive` из корня) не сработает — путь должен вычисляться от расположения скрипта.
5. **`web/app.py`**: дефолт `DOCUMENTS_PATH = web/examples/sample_library` указывает на несуществующую папку (examples лежит в корне репо) — локальный запуск без env-переменной покажет пустую библиотеку. На Render проблему маскирует render.yaml.
6. **Потенциальная уязвимость, `web/app.py`**: `/download/<path:file_path>`, `/api/file/<path:...>`, `/api/folder/<path:...>` конкатенируют пользовательский путь с корнем без проверки выхода за пределы (`send_file` вместо `send_from_directory`, нет resolve+containment-проверки) — риск path traversal. В рантайме не эксплуатировалось (не проверено), но паттерн небезопасный.
7. Мелочи: flask-cors в requirements, но CORS в app.py не инициализируется; `$id` схем содержит placeholder `yourusername/file-metadata-system`; голые `except:` в нескольких местах глотают ошибки.

## Плюсы

- Ясная, самостоятельная концепция; методология переиспользуема даже без этого кода.
- CLI-ядро без зависимостей — легко встроить куда угодно.
- Наличие формальных JSON Schema.
- Необычно богатая документация и продуманный UI-слой.
- Готовые конфиги деплоя (Render Blueprint, Procfile).

## Минусы

- Ключевая функция (поиск) сломана в веб-версии; ни один тест этого не поймал бы, потому что тестов нет.
- Копипаста модуля вместо пакетирования; хрупкие относительные пути.
- Документация обещает в разы больше, чем реализовано, — вводит в заблуждение о статусе.
- Демо-данные противоречат сами себе; инструкция деплоя устарела в день создания.
- Разработка остановилась в день рождения проекта; сопровождения нет.

## Качество кода и документации

Код: аккуратный, единообразный стиль, типовые подсказки, русские docstrings — читается легко, но это «код одного прохода» без ревью и запуска: класс ошибок (незамкнутые импорты, копипаста-переменные, неверный suffix) характерен для сгенерированного и не прогнанного кода. Документация: объёмная и структурированная, но на ~60% описывает нереализованное; как спецификация — хороша, как описание продукта — завышает статус.

## Зрелость: 2/5

Обоснование: продуманная концепция, формальные схемы и работающее CLI-ядро поднимают выше 1; но отсутствие тестов, CI, лицензии-файла, упаковки, сломанный веб-поиск, небезопасные эндпоинты и полная остановка активности после единственного дня разработки не позволяют дать 3. Это демонстрационный прототип, а не готовый инструмент.
