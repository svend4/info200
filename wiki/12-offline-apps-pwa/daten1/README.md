# daten1 — офлайн-блокноты на SQLite-in-browser и браузерные игры

## Обзор

**daten1** — репозиторий-витрина одиночных HTML-приложений (описание на GitHub: «Info блокнот, игры»). Внутри — три самостоятельных пласта:

1. **Пять вариантов офлайн-блокнота** — одностраничные приложения (один HTML-файл = всё приложение), где в браузере через `sql.js` (SQLite, скомпилированный в WebAssembly) работает настоящая реляционная база данных, сохраняемая в `localStorage`. Флагман — `notebook-2d-mega.html` («МЕГА Блокнот — 100+ функций», ~4000 строк, 167 КБ): Markdown, wiki-ссылки `[[...]]`, обратные ссылки (backlinks), вложенные папки, шаблоны, дашборд с графиками Chart.js, диаграммы Mermaid, экспорт в 5 форматов, PWA (manifest.json + service worker).
2. **Три варианта аркады «Космический Защитник»** — 2D (Canvas), 2.5D и 3D (Three.js r128), с сенсорным управлением для мобильных.
3. **Учебные материалы по геймдеву на русском** — `browser-games-guide.md` (~1000 строк: Canvas, WebGL, Phaser, Three.js, PixiJS, полный пример Arkanoid, публикация, монетизация), `computer-games-types.md` (таксономия жанров), `minimal-game-development.md` (минимальные игры на Python/Pygame и JS).

Отдельно лежит архив `flower_shop_master_levels_v7.zip` (114 файлов) — «цветочный магазин в 7 уровнях сложности стека»: от PHP+SQLite в одном файле до Next.js и enterprise-микросервисов с Docker/nginx/Postgres/RabbitMQ/Kubernetes. Тематически он ближе к репозиториям daten2 и meta4, здесь выглядит «складом».

## Назначение и идея

Идея репозитория — показать, как далеко можно уехать на **одном HTML-файле без сервера и установки**: полноценный блокнот с реляционной БД, версионированием заметок, многопользовательскими профилями и офлайн-режимом PWA; и рядом — игры, иллюстрирующие путь 2D → 2.5D → 3D. Материалы-гайды закрывают образовательную часть: «что нужно, чтобы сделать минимальную игру» и «как устроены браузерные игры». Судя по истории коммитов (соавтор — claude), это спринт генеративной разработки: за два дня (18–19 декабря 2025) собрано и итеративно доработано всё основное содержимое.

## Как устроено (архитектура)

- **Плоская структура**: 15 файлов в корне, папок нет.
- **Каждое приложение — самодостаточный HTML-монолит**: стили, разметка и JS в одном файле; внешние зависимости подтягиваются с CDN (cdnjs/jsdelivr): `sql.js 1.8.0`, `marked 4.3.0`, `jsPDF 2.5.1`, `Chart.js 4.4.0`, `highlight.js 11.9.0`, `mermaid@10`, `three.js r128`.
- **Персистентность**: база SQLite экспортируется в массив байт и сохраняется в `localStorage` (`JSON.stringify(Array.from(db.export()))`) — работает, но крайне неэкономно по месту (см. [оценку](assessment.md)).
- **PWA-обвязка** (`manifest.json`, `sw.js`) настроена только на mega-версию: cache-first service worker кэширует сам HTML и CDN-библиотеки для офлайн-работы.
- **Линейка версий блокнота** — фактически эволюционные ступени одного приложения: `notebook-2d.html` (мультипользователь + SQLite) → `notebook-2.5d.html` (объёмный визуал) → `notebook-3d.html` (Three.js) → `notebook-2d-ultra.html` (папки, история заметок, корзина, экспорт) → `notebook-2d-mega.html` (всё вышеперечисленное + шаблоны, дашборд, achievements, bulk-операции, drag&drop, напоминания, тёмная тема, горячие клавиши).

Подробное дерево — в [structure.md](structure.md).
