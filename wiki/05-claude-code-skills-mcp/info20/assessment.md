# Характеристика и оценка info20

## Что есть

- **Цельное методическое пособие** (~4670 строк markdown в 7 файлах) по пяти способам расширения Claude Code: Skills, MCP, агенты, RAG-инструкции в репозитории, практические примеры.
- **Ясная концептуальная рамка**: трёхуровневая модель (встроенные инструменты → внешние инструменты → база знаний) и лозунг «не всё должно быть встроено в нейросеть» — идея RAG-подхода к инструкциям изложена доходчиво и последовательно проведена через все разделы.
- **Рабочая внутренняя навигация**: оглавления с якорями, перекрёстные относительные ссылки между разделами docs/ (проверены выборочно — ведут на существующие файлы).
- **Много конкретики**: пошаговые инструкции, frontmatter-шаблоны skills, полный пример MCP-сервера на `@modelcontextprotocol/sdk` (Node.js), JSON-конфигурации, 3 сквозных сценария и 3 шаблона проектов в `docs/examples/README.md`, таблицы «когда использовать что».
- **Сравнительные таблицы** методов по сложности/гибкости/скорости и рекомендуемый путь внедрения по неделям — полезная дидактика.

## Чего нет

- **Файла LICENSE** — README заявляет «Лицензия: MIT», но `LICENSE`/`LICENSE.md` отсутствуют (проверено: 404). Формально права использования не определены.
- **CLAUDE.md** — репозиторий, обучающий писать CLAUDE.md, сам его не имеет.
- **Работающих артефактов**: нет ни одного реального skill-файла, MCP-конфига или агента, которые можно было бы взять и запустить, — всё существует только как код-блоки в тексте.
- **CI и проверки качества**: нет проверки ссылок (link checker), линтера markdown, spell check.
- **Тестов** — неприменимо к чистой документации, но и примеры кода нигде не были исполнены/проверены.
- **Версионирования и changelog**: единственная «версия 1.0» от 2026-02-09; механизма актуализации под быстро меняющийся Claude Code нет.
- **Указания источников**: непонятно, что взято из официальной документации, а что домыслено.

## Плюсы

- Понятная структура и единый стиль изложения; хорошее оглавление в каждом файле.
- Правильная и до сих пор актуальная центральная идея (контекст-инжиниринг: CLAUDE.md, docs-как-RAG, прогрессивная подгрузка знаний).
- Пример MCP-сервера использует реально существующий пакет `@modelcontextprotocol/sdk` и корректную общую архитектуру client/server, Resources/Tools/Prompts.
- Практические сценарии в examples/ реалистичны как учебные кейсы (Next.js + Prisma, миграция JS→TS).
- Низкий порог входа для русскоязычного читателя — таких систематических русских пособий по Claude Code мало.

## Минусы

- **Фактические ошибки в технических деталях** (главная проблема; пособие писалось моделью без сверки с реальностью):
  - `docs/mcp/README.md`: пути конфигурации `~/.claude/mcp.json` и `/проект/.claude-mcp.json` — вымышленные; реальный Claude Code использует `.mcp.json` в корне проекта, `claude mcp add` и `~/.claude.json`;
  - `docs/agents/README.md`: `npm install @anthropics/claude-agent-sdk` — неверное имя пакета (реально `@anthropic-ai/claude-agent-sdk`); API `new Agent({name, systemPrompt, ...})` — вымышленный (реальный SDK строится вокруг функции `query()`);
  - `docs/skills/README.md`: формат «skill = один markdown-файл с frontmatter `invocation`/`args`» не совпадает с реальным (`.claude/skills/<имя>/SKILL.md` с `name`/`description`); понятия slash-команд (`.claude/commands/`) и skills смешаны; таблица «встроенных skills» (`/commit`, `/review-pr`) сомнительна;
  - битые/устаревшие внешние ссылки: `github.com/anthropics/claude-agent-sdk`, `github.com/anthropics/claude-code-skills` (не существует), `docs.anthropic.com/claude/docs/claude-code` (устаревший URL);
  - «molt bot — локальный ассистент» — неопознанная сущность, не проверено.
- Заявленная MIT-лицензия без файла LICENSE.
- Дублирование: архитектурная диаграмма и таблицы повторяются в корневом README и docs/README.md почти дословно.
- Контент заморожен на февраль 2026 и уже расходится с актуальным Claude Code.
- Нулевая вовлечённость сообщества (0 звёзд/форков), хотя раздел «Вклад» приглашает к дополнениям.

## Качество кода и документации

Кода как такового нет — только примеры в код-блоках. Их качество неровное: MCP-пример близок к реальному SDK, а примеры Agent SDK полностью вымышлены. Документация как текст — хорошая: связная, структурированная, с таблицами и диаграммами, на грамотном русском. Но как **справочник** она ненадёжна: читатель, дословно следующий инструкциям (имя пакета, пути конфигов, формат skills), столкнётся с ошибками. Это типичный результат односессионной генерации LLM без валидации.

**Перепроверка самозаявлений** (аудит-перепроверка): собственных самоаудитов/отчётов в репозитории нет. Заявления README проверены: структура docs/ и все 6 обещанных разделов реально существуют и наполнены (совпадает); «Лицензия MIT» — файла нет (не совпадает); «Версия 1.0, 2026-02-09» — совпадает с датой коммитов; ветка PR называлась `claude/review-repository-U80Tv`, но никакого файла-ревью в репозитории не осталось — PR добавил только документацию.

**Покрытие аудита**: полностью прочитаны корневой README и docs/README.md; skills, mcp, agents — прочитаны на ~40–60% (начала, ключевые разделы, полная структура заголовков); rag-instructions и examples — по структуре заголовков и выборочным фрагментам. Ошибки перечислены только там, где текст просмотрен непосредственно; в непрочитанных частях rag-instructions/examples возможны аналогичные неточности (не проверено).

## Зрелость: 2/5

Обоснование: это завершённое, объёмное и хорошо структурированное пособие (что поднимает оценку выше 1), но: единственная итерация без ревизии, существенные фактические ошибки в ключевых технических деталях, нет лицензии-файла, нет работающих примеров-артефактов, нет механизма актуализации, нулевое сообщество. Для справочного ресурса достоверность — главный критерий, и именно она здесь хромает.
