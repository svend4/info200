## Особенности организации

- **Единый шаблон разделов**: каждый файл имеет оглавление с якорями, ASCII-диаграммы, таблицы сравнения, блоки «Best Practices» и «Дальнейшее чтение» с относительными ссылками на соседние разделы — навигация внутри docs/ связная и рабочая.
- **Один README на папку**: подпапки `docs/*` содержат ровно по одному `README.md`; заявленные в примерах вспомогательные файлы (шаблоны, skills, конфиги) существуют только как код-блоки внутри текста, не как реальные файлы.
- **Русский язык** повсюду, включая комментарии в примерах кода; примеры кода — TypeScript/JavaScript (Next.js, Prisma, Express, React), bash и JSON.
- **Однородное происхождение**: весь контент добавлен одним коммитом claude (PR #1), стилистически монолитен; в подвале каждого файла «Версия 1.0, Дата 2026-02-09, Создано с помощью Claude Code».
