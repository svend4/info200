# info20 — руководство по расширению возможностей Claude Code (чистая документация)

## Обзор

**info20** — это документационный репозиторий (без кода), содержащий русскоязычное методическое пособие по расширению возможностей Claude Code. Весь контент — 7 markdown-файлов общим объёмом около 4670 строк (~132 КБ; проверено — 134 996 байт): корневой README и папка `docs/` с шестью руководствами по темам: Skills, MCP Protocol, агенты и оркестраторы, RAG-подобные инструкции в репозитории и практические примеры.

Репозиторий создан за один заход: практически весь контент добавлен одним PR (#1, ветка `claude/review-repository-U80Tv`, автор коммита — claude) 9 февраля 2026 года и смёржен 18 апреля 2026 года. Заявленная версия — 1.0.

## Назначение и идея

Центральная идея пособия сформулирована прямо в README: **«Не всё должно быть встроено в нейросеть!»** По аналогии с RAG (Retrieval-Augmented Generation) Claude Code может подгружать знания и возможности из внешних источников:

- **CLAUDE.md и docs/** — инструкции и база знаний прямо в репозитории проекта;
- **Skills** — кастомные команды для повторяющихся задач;
- **MCP Protocol** — интеграция с файловой системой, БД, внешними API;
- **Агенты** (Claude Agent SDK) — автономные многоэтапные задачи и оркестрация;
- **Локальные боты** — вспомогательные сервисы (упоминается некий «molt bot» — не проверено).

Пособие адресовано разработчикам, которые хотят системно «прокачать» Claude Code под свой проект: от минимальной настройки (один CLAUDE.md) до «enterprise»-схемы с `.claude/{memory,skills,instructions,templates}`, MCP-конфигурацией и кастомными агентами.

## Как устроено (архитектура)

Документация построена вокруг трёхуровневой модели расширения (ASCII-диаграммы повторяются в корневом README и `docs/README.md`):

1. **Уровень 1 — встроенные инструменты**: Read, Write, Edit, Bash.
2. **Уровень 2 — внешние инструменты**: Skills, MCP, агенты.
3. **Уровень 3 — база знаний**: CLAUDE.md, документация, память, шаблоны.

Каждый метод разобран в отдельном разделе `docs/<тема>/README.md` по единой схеме: «что это» → аналогия → архитектура → пошаговая настройка → примеры → best practices → отладка. Разделы связаны перекрёстными ссылками, есть сравнительные таблицы («когда использовать что») и рекомендуемый путь внедрения по неделям.

**Важная оговорка аудита:** часть технических деталей в пособии не соответствует реальному Claude Code — придуманы пути конфигурации (`.claude-mcp.json`, `~/.claude/mcp.json`), неверное имя npm-пакета SDK (`@anthropics/claude-agent-sdk` вместо `@anthropic-ai/claude-agent-sdk`) и вымышленный API (`new Agent({...})`), формат Skills с полями `invocation`/`args` не совпадает с реальным `.claude/skills/<name>/SKILL.md`. Подробнее — в [оценке](assessment.md).
