# Структура claudeai-test-project-k

Репозиторий плоский, без подкаталогов. Полное дерево (все файлы прочитаны при аудите):

```
claudeai-test-project-k/
├── .gitignore     # типовые исключения Python/IDE/ОС (24 строки);
│                  #   наличие desktop.ini и Thumbs.db указывает на Windows-окружение
├── README.md      # русскоязычное описание проекта (54 строки): установка, запуск,
│                  #   структура, чек-лист «Что дальше» (5 невыполненных пунктов),
│                  #   дата создания 01.02.2026
└── hello.py       # единственный исполняемый файл (31 строка):
                   #   интерактивный приветственный скрипт на Python 3
```

## Ключевые файлы

| Файл | Что делает | Примечания |
|---|---|---|
| `hello.py` | Печатает баннер «ДОБРО ПОЖАЛОВАТЬ В ТЕСТОВЫЙ ПРОЕКТ!», запрашивает имя через `input()`, выводит `Привет, {имя}! 👋` через функцию `greet(name)` | Есть шебанг, `# -*- coding: utf-8 -*-`, докстринги у модуля и обеих функций, идиома `if __name__ == "__main__"`. Требует Python ≥ 3.6 (f-строки). Зависимостей нет |
| `README.md` | Документация: описание, запуск (`python hello.py`), структура, план развития | В блоке «Структура проекта» указан каталог `test_project/` только с двумя файлами — реальный репозиторий называется иначе и содержит ещё `.gitignore` (мелкое расхождение). Пункты чек-листа «Инициализировать Git» и «Загрузить на GitHub» не отмечены выполненными, хотя фактически сделаны |
| `.gitignore` | Исключает `__pycache__/`, `*.py[cod]`, `venv/`, `build/`, `dist/`, `*.egg-info/`, `.vscode/`, `.idea/`, `.DS_Store`, `Thumbs.db`, `desktop.ini` | Заготовка «на вырост»: в репозитории пока нечему попадать под эти правила |

## Особенности организации

- **Один коммит, одна ветка.** Вся история — коммит от 01.02.2026 (автор Stefan). Ветка `master`, тегов и issues нет.
- **Зафиксированный артефакт бага кодировки.** Сообщение коммита в интерфейсе GitHub выглядит как `Initial commit: ð┤ð¥ð▒ð░ð▓ð╗ðÁð¢ hello.py ð© README` — это UTF-8-байты фразы «добавлен hello.py и README», прочитанные как однобайтовая кодовая страница консоли (характерно для Windows: CP437/CP866). Это главная «ценность» репозитория как теста: он наглядно демонстрирует место разрыва — файлы через Desktop Commander записались в корректном UTF-8, а строка, переданная в `git commit -m` через терминал, испортилась.
- **Нет ни тестов, ни CI, ни лицензии, ни requirements.txt** — только три перечисленных файла; каталогов `tests/`, `.github/` и т.п. не существует (проверено по корневому листингу GitHub).
- **Документация превышает код по объёму**: 54 строки README против 31 строки Python — типично для демонстрационного/учебного репозитория.
