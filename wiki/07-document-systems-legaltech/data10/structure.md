## Ключевые файлы и модули

| Файл / раздел | Что делает |
|---|---|
| `README.md` | Заглушка: название + слово «info». Не описывает содержимое репозитория |
| `dynamic_content_blocks_methodology.md` | Единственный содержательный артефакт: полное проектное руководство (теория → архитектура → код → деплой → roadmap) для системы динамических контент-блоков |
| — разделы 2–3 | Теоретический фундамент: графы, логика, NLP, паттерны |
| — раздел 4 | Проектируемая структура кодовой базы `content-blocks-system/` (app/models, services, repositories, api, tests, docker) — существует только на бумаге |
| — разделы 6–8 | Наиболее прикладная часть: парсеры немецких законов, сборка юридических документов (Widerspruch, Antrag) |
| — раздел 7 | Самая оригинальная идея: Smart Inserter с автоматической эскалацией детализации контента |
| — разделы 9–11 | Версионирование блоков, конфликт-детекция, suggestion engine, Docker/K8s |

## Особенности организации

- **Код только внутри markdown**: ~132 code-фенса, из них 36 — Python; также cypher (2), yaml (2), dockerfile, jinja, javascript, json. Ни один не извлечён в исполняемые файлы.

- **История тривиальна**: 2 коммита за один день (05.02.2026), веток кроме main не видно (наличие других веток детально не проверялось), issues/PR отсутствуют.
