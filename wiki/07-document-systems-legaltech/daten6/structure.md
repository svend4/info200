## Ключевые файлы и модули

| Файл | Роль | Комментарий аудита |
|---|---|---|
| `README.md` | Витрина проекта | Хорошо оформлен; содержит устаревшие/завышенные утверждения (см. assessment) |
| `BRANCHES.md` | Навигация по веткам | Полностью устарел: описанных веток не существует, всё в `main` |
| `docs/ARCHITECTURE.md` | Архитектура базовой системы | Ясные принципы и слои; без кода |
| `docs/TECHNICAL_SPECIFICATION.md` | Техспецификация | Подробная: REST-endpoints, React-компоненты, WebSocket, безопасность — всё «на бумаге» |
| `docs/DATABASE_SCHEMA.md` | Схема MongoDB | Mongoose-схемы, индексы, агрегации, миграции — не подкреплены кодом |
| `docs/IMPLEMENTATION_PLAN.md` | План на 8–12 недель | Выполнен только «Этап 0» |
| `docs/VERSIONING_SYSTEM.md` + `PLUGIN_ANCHOR_SYSTEM.md` | Версионированная система | Самая оригинальная часть: многомерные версии + якоря-плагины |
| `docs/APPENDIX_3_V2_PART_1..5` | Методология компиляции документов | ~10 тыс. строк; самостоятельный продукт, слабо связанный с каталогом как таковым |
| `prototype/app.js` | Логика прототипа | Работает; есть баги: рассинхронизация индексов при поиске, `?path` не восстанавливается при перезагрузке, `innerHTML` без экранирования |
| `prototype/data.js` | Мок-данные | Навигабельны только цепочки «марки» и «меню» (2 из 8 категорий); счётчики childrenCount (245, 89, 123…) — декоративные |

## Особенности организации кода

- **Документация доминирует**: код составляет ~6% объёма (1,6 тыс. строк из ~26 тыс.). GitHub из-за этого определяет языки как «CSS 76% / HTML 24%» (Markdown не учитывается; почему не учтён JavaScript прототипа — не проверено).
- **Три слабо связанных пласта в одном репо**: каталог (база), версионированная система (концепт) и методология APPENDIX_3 (универсальная, используется в кейсах других репозиториев профиля). Внутренние перекрёстные ссылки есть, но границы пластов в структуре папок не выделены — всё лежит плоско в `docs/`.
- **Прототип образцово автономен**: нулевые зависимости, открывается двойным кликом; комментарии на русском, код разбит на секции-баннеры.
- **Следы AI-генерации**: коммиты от автора `claude`, ветки `claude/*`, характерное эмодзи-оформление документов; даты внутри документов («2024-12-28») расходятся с реальными датами коммитов (2025-12-28/29) на год.
- **Нет служебных файлов**: отсутствуют `.gitignore`, `.gitattributes`, LICENSE, `package.json`, CI-конфиги — репозиторий не оформлен как программный проект.
