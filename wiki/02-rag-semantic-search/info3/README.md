# info3 — «гуманитарные формулы»: 4-уровневая база знаний + псевдо-RAG на Python

## Обзор

**info3** — экспериментальный проект svend4, соединяющий две части:

1. **Гуманитарный контент** — большая коллекция афоризмов и «формул человеческих качеств», организованная по принципу пар-противоположностей (сила-и-слабость, доверие-и-подозрительность, щедрость-и-скупость и т.д.). Ядро — папка `афоризмы/`, которая по собственной статистике содержит ~437 тематических разделов, 446 текстовых файлов и ~90 000 афоризмов (выборочно перепроверено: подпапки реально существуют).
2. **Технический слой** — папка `machine-readable/` с 35 Python-модулями (~24 700 строк), реализующими «псевдо-RAG»: микро-агент-посредник между LLM и базой знаний, семантический поиск (sentence-transformers + FAISS), персистентное хранилище, production REST API (FastAPI, JWT, rate limiting, Prometheus), WebSocket-сервер и React-дашборд (`frontend/`).

Описание репозитория на GitHub: «Info, гуманитарные формулы, 4х частная система внутри псевдо RAG, формулы архетипы алгоритмы теоремы».

## Назначение и идея

Центральная идея — **4-уровневая система познания**: любую тему можно описать на четырёх уровнях абстракции:

1. **Формула** — математическая абстракция (например, `AI = Data × Algorithm × Compute`);
2. **Архетип** — развёрнутая формула с компонентами;
3. **Алгоритм** — пошаговый процесс / блок-схема;
4. **Теорема** — конкретное житейское утверждение с примерами и афоризмами.

Поверх этой системы построен «информационный Redis» — микро-агент, который перед решением новой задачи проверяет базу накопленного опыта (см. `machine-readable/RAG-ARCHITECTURE-ANALYSIS.md`). Проект намеренно разложен на 6 «уровней реальности» — от рабочего кода (семантический поиск, API) до откровенной научной фантастики (модули `akashic_records.py`, `knowledge_telepathy.py`, `quantum_knowledge.py`), причём фантастические модули честно помечены в докстрингах оценками «Reality: 1–30%».

## Как устроено (архитектура)

- **Данные (гуманитарная часть)**: корневые папки с русскими именами (21 пара качеств: `сила-и-слабость/`, `усердие-и-халатность/` …), в каждой — один `.txt` с афоризмами; плюс огромная коллекция `афоризмы/` с сотнями тематических подпапок (философия, технологии, эмоции, природа и т.д.).
- **Машиночитаемые форматы**: `machine-readable/искусственный-интеллект.json` и `.yaml` — эталонная тема, размеченная по 4 уровням (JSON валиден, проверено).
- **Код**: 35 автономных модулей, каждый с демо-блоком `if __name__ == "__main__"`; все компилируются (`py_compile` пройден). Ключевая цепочка: `micro_agent_simple.py` (без зависимостей, запуск проверен — работает) → `semantic_search_agent.py` (FAISS/эмбеддинги с graceful fallback) → `rag_api_server.py` / `production_api.py` / `websocket_server.py` → `frontend/` (React 18 через CDN, без сборки).
- **Документация**: 7 md-файлов в `machine-readable/` (~8 100 строк), включая самоаудит `IMPLEMENTATION-STATUS.md` (3 810 строк) и дорожную карту `FUTURE-ROADMAP.md`.
