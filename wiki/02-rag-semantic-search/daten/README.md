# daten — «Информационная операционная система» (IOS): от экспорта чата к деплоируемому веб-приложению

## Обзор

`daten` — один из самых крупных и насыщенных репозиториев профиля svend4. Описание репозитория — «иос - инфо операцион система», где IOS означает **Information Operating System** (не Apple iOS): концепция управления знаниями, построенная по аналогии с компьютерной операционной системой (ядро, службы, файловая система, граф знаний, поисковый движок, API).

Репозиторий прошёл заметную эволюцию:

1. **Исходная точка (декабрь 2025)** — экспорт данных из Claude: две конверсации (182 сообщения про «информационную ОС» + проект сайта турагентства), из которых было автоматически извлечено ~1118 файлов кода с именами вида `msg047_043.py`.
2. **Фаза структурирования** — файлы разложены по иерархии `IOS-System/` (core, services, api, utils, tests, scripts и т.д.), создан индекс `INDEX.md`.
3. **Фаза самоаудита** — написаны `AUDIT_ANALYSIS.md` (анализ 7 внутренних аудитов, вывод: разрыв 65–75% между документацией и кодом) и `IMPLEMENTATION_PLAN.md` (план MVP на 4–8 недель).
4. **Фаза bootstrap и деплоя (13–16 декабря 2025)** — поверх архива построен запускаемый каркас: минимальное FastAPI-приложение `ios_bootstrap/`, «полный» бэкенд `main_production.py` с сервисами-заглушками, React/TypeScript-фронтенд (30+ страниц в 9 разделах), два Dockerfile и конфиги деплоя на Railway.
5. **Хвост активности (январь 2026)** — тестовая заметка `notes/claude-test.md`, записанная из чата Claude через Make.com.

## Назначение и идея

Идея IOS — иерархическая система управления знаниями «как операционная система»:

- **Ядро (core)** — IOSRoot (корневой интерфейс), Domain (тематические домены), граф знаний, распознавание сущностей;
- **Службы (services)** — поисковый движок (Whoosh/Elasticsearch), индексатор документов, менеджер контекстов, аналитика графа;
- **API** — REST (FastAPI), задел под WebSocket и GraphQL;
- **UI** — React SPA: документы, поиск (включая семантический), граф знаний, аналитика, безопасность, администрирование, коллаборация.

Практическая цель декабрьского спринта — превратить «код из конверсации» в реально деплоируемое приложение (Railway, Docker), двигаясь инкрементально: Level 0 (инфраструктура) → Level 1 (БД) → Level 2 (поиск) → Level 3 (аутентификация) → Level 4 (кэш) → Level 5 (продвинутые функции).

## Как устроено (архитектура)

Три слоя (подробнее — в [structure.md](structure.md)):

1. **Архив-источник**: ~1118 файлов `msgNNN_NNN.*` (Python, TypeScript, Kotlin, Shell, YAML, Markdown) в `ios-system/IOS-System/{core,services,api,utils,config,docs,tests,scripts}` — сырой код из конверсации, по большей части не подключённый к приложению.
2. **Запускаемый каркас**:
   - `ios_bootstrap/` — минимальное FastAPI-приложение (health, /api/status, docs, раздача SPA) + 7 интеграционных тестов;
   - `IOS-System/main_production.py` — «полная» архитектура: IOSApplication с EventBus, ServiceRegistry, DatabaseManager (PostgreSQL), RedisCache, пятью сервисами и роутерами `api/routes.py`. **Важно: сервисы — тонкие заглушки** (например, `SearchService.search()` возвращает `[]`), а API работает на in-memory демо-данных (DEMO_USERS с паролями `admin123`/`demo123`, DEMO_DOCUMENTS);
   - `frontend/` — React 18 + Vite + Tailwind + zustand + react-query + recharts; 7 базовых страниц + 9 разделов (documents, search, graph, analytics, security, api, admin, collaboration, ai), добавленных «этапами 1–7» 16 декабря 2025.
3. **Деплой**: `Dockerfile` (bootstrap-режим) и `Dockerfile.fullstack` (полный режим), `railway.json/.toml/.bootstrap.json/.fullstack.json`, `Procfile`, `start_fullstack.py`; переключение режимов описано в `TESTING_FULLSTACK.md`.

## Статус и активность

- **117 коммитов**; основной всплеск — 13–16 декабря 2025 (извлечение архива, bootstrap, фронтенд-этапы 1–7, мерджи PR #39–#40 из веток `claude/*`); последний коммит — **12 января 2026** («Add test note from Claude chat» — тривиальная заметка через Make.com).
- На момент аудита (июль 2026) — **~6 месяцев без содержательной активности**; проект остановлен на «Level 0 завершён, Level 1 (БД) — 0%».
- CI настроен (`.github/workflows/ci.yml`), но **сломан**: все шаги ссылаются на каталог `информационная-ОС`, который был переименован в `ios-system` (проверено: старого пути в репозитории нет).
- Корневой `README.md` **устарел**: описывает файлы `conversations.json`, `projects.json`, `users.json`, `memories.json`, zip-архив и папку `туристическое-агентство/` — всё это из репозитория удалено (проверено, 404).
