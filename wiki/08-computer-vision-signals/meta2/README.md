# meta2 — восстановление разорванных документов (puzzle-reconstruction)

## Обзор

**meta2** — самый крупный и инженерно наиболее зрелый код-проект профиля svend4: Python-пакет `puzzle-reconstruction` для **автоматической сборки разорванных газет, книг и документов из отсканированных фрагментов**. Это не «info»-репозиторий с заметками, а полноценная production-система: 305+ модулей (~93–105 тыс. строк исходного кода по разным снимкам), более 1000 тестовых файлов (десятки тысяч pytest-тестов), CI на GitHub Actions с 6 джобами, Docker/docker-compose, Makefile, REST API-сервер и ~4,5 тыс. строк проектной документации на русском языке.

Проект разработан в формате интенсивного AI-спринта: ~471 коммит за 9 дней (20–28 февраля 2026), основной автор коммитов — «claude» (ассистент), владелец svend4 — около 5 коммитов. Версия — **1.0.0 Production/Stable** (по метаданным `pyproject.toml`).

## Назначение и идея

Задача — «пазл наоборот»: по набору сканов рваных клочков восстановить исходный лист. Ключевая идея (описана в `PUZZLE_RECONSTRUCTION.md`, 868 строк) — **двойное описание каждого края фрагмента**:

1. **Танграм-аппроксимация** (изнутри): выпуклая оболочка → упрощение Рамера–Дугласа–Пекера → нормализация. Даёт крупную геометрию фрагмента.
2. **Фрактальная кромка** (снаружи): фрактальная размерность края тремя методами (Box-counting, Divider/Ричардсон, IFS Барнсли) + CSS-дескриптор (Curvature Scale Space, MPEG-7). Даёт «форму береговой линии» разрыва.

**Синтез**: `B_virtual = α·B_tangram + (1−α)·B_fractal` — уникальная «подпись» края (`EdgeSignature`), инвариантная к освещению и параметрам сканирования. По подписям строится матрица совместимости N×N (CSS + DTW + фрактальная размерность + текстовые подсказки OCR), после чего глобальная сборка выполняется одним из **8 алгоритмов**: полный перебор, beam search, MCTS, генетический, муравьиная колония, гамма-оптимизатор, имитация отжига, жадный (плюс режимы `auto` и `all`). Результат проверяется **21 валидатором** (`VerificationSuite`), включая OCR-верификацию текстовой связности через Tesseract.

Заявленная область применения — форензика, архивистика, восстановление уничтоженных документов (в документации упоминаются вдохновившие образы из «Особого мнения» и «Игр разума»).

## Как устроено (архитектура)

Шестиэтапный конвейер (класс `Pipeline` в `puzzle_reconstruction/pipeline.py`, ~1086 строк):

```
Сканы фрагментов → 1. PREPROCESS (38 фильтров) → 2. SEGMENT (Otsu/Adaptive/GrabCut)
→ 3. DESCRIBE (Танграм + Фрактал → EdgeSignature) → 4. MATCH (матрица совместимости,
реестр 13+ матчеров) → 5. ASSEMBLE (8 алгоритмов через реестр) → 6. VERIFY (21 валидатор + OCR)
```

Пакет разбит на 9 подпакетов: `preprocessing/` (38 модулей), `algorithms/` (42, включая `tangram/` и `fractal/`), `matching/` (26), `assembly/` (27), `verification/` (21), `scoring/` (12), `io/` (3), `ui/` (1, интерактивный просмотрщик), `utils/` (130). Расширяемость — через реестры с декоратором `@register` (матчеры, алгоритмы сборки, валидаторы). Точки входа: CLI `main.py` (1553 строки, ~30 опций) и Flask REST API `tools/server.py` (OpenAPI-спецификация, `/api/reconstruct` и др.). Тестовые данные генерируются синтетически (`tools/tear_generator.py` «рвёт» изображение на N фрагментов). Подробнее — в [structure.md](structure.md).
