# info100 — «Эволюционная лаборатория агентов»: автоматический цикл сбора знаний, синтеза и тестирования ИИ-скиллов

## Обзор

**info100** — небольшой Python-монорепозиторий, оформленный как «эволюционная лаборатория агентов». Идея: агенты-сборщики забирают знания из других репозиториев профиля svend4 (конкретно `info1` и `data70`), из них извлекаются «методологии», из методологий синтезируются «скиллы» (пары YAML + Python), скиллы автоматически тестируются, получают fitness_score и перемещаются в `tested/` или `retired/`. Весь цикл упакован в GitHub Actions workflow с ежедневным cron-запуском.

Репозиторий был создан 17 апреля 2026 и за 5 дней (17–21 апреля) прошёл один полный цикл «эволюции»: собраны данные из info1 (534 объекта) и data70, извлечена методология «параллельного двунаправленного развития», синтезировано 4 скилла, один прошёл тесты с fitness 1.0, отчёт опубликован в Issue #1. После 21 апреля 2026 активности нет: последние два запуска Actions упали, ежедневный cron не срабатывает (проверено по вкладке Actions — всего 6 запусков, все в апреле).

## Назначение и идея

Заявленная цель (README репозитория): «выращивать мыслящие системы» — превращать внешние репозитории в структурированные методологии, скрещивать их и отбирать жизнеспособные скиллы по метрикам. Ключевые метафоры: агенты как «геномы» (родители, мутации, fitness_score, lineage), процесс из четырёх стадий:

1. **Ingest** — сборщики (`pipelines/ingest/*.py`) через GitHub API извлекают структуру и README внешних репо в `knowledge/raw/`;
2. **Distill** — из сырых данных извлекается абстрактная методология (`knowledge/methods/*.yaml`);
3. **Synthesize** — синтезатор (`skill-synthesizer.py`) генерирует из методологии и графа связей исполняемый скилл (YAML-манифест + Python-код);
4. **Validate** — тестер (`skill-tester.py`) прогоняет 3 проверки (синтаксис, импорт, функциональный вызов `process()`), вычисляет fitness (0.0–1.0) и сортирует скиллы: ≥0.7 → `tested/`, 0.3–0.7 → остаётся в `generated/`, <0.3 → `retired/`.

Практически репозиторий — это работающий прототип конвейера «репозиторий → знание → код», а не зрелая платформа: реально извлечена одна методология, синтезированы простые скиллы-заглушки (сгенерированный код лишь возвращает словарь-статус).

## Как устроено (архитектура)

- **`agents/`** — декларативные описания агентов; реально существует один: `core/base-collector.yaml` (эталон, fitness 1.0). Заявленные в README папки `evolved/` и `variants/` отсутствуют.
- **`pipelines/`** — 6 Python-скриптов: два сборщика (`info1-collector.py`, `data70-collector.py`), два синтезатора (`skill-generator.py` — черновой, с багом подстановки шаблона; `skill-synthesizer.py` — основной рабочий), тестер `skill-tester.py` и репортёр `issue-reporter.py` (публикует сводку в GitHub Issues).
- **`knowledge/`** — собранные данные: `raw/info1/` (структура из 437 файлов и 97 папок в `.structure.json`), `raw/data70/` (17 md/json-файлов анализа 1105 диалогов ChatGPT), одна методология `methods/parallel-bidirectional.yaml`, мини-граф `graph/concepts.json` (5 узлов, 4 ребра).
- **`skills/`** — шаблон, 2 сгенерированных скилла и 1 протестированный (`tested/test-agent-v1.yaml`, fitness 1.0).
- **`benchmarks/`** — раннер-заглушка `run.py` (симулирует тесты), 3 стандартные задачи, 1 реальный результат прогона.
- **`meta/`** — лог эволюции (4 события синтеза в JSONL) и `last-report.json` (Issue #1).
- **`.github/workflows/evolve.yml`** — 4-стадийный CI-пайплайн (collect → synthesize → validate → report) с cron `0 4 * * *` и ручным запуском; результаты передаются между job'ами через артефакты, коммитит «Evolution Bot».

Подробное дерево — в [structure.md](structure.md).

## Статус и активность

- 16 коммитов, все между 17 и 21 апреля 2026; авторы — «Pro» и «Evolution Bot» (автокоммиты workflow).
- 6 запусков GitHub Actions: 4 успешных, последние 2 (17 и 21 апреля) — провал; с тех пор cron ни разу не отработал — **автоматизация фактически мертва**, несмотря на «ежедневный» график.
- 1 открытый Issue (автоотчёт об эволюции), 0 звёзд, релизов нет, лицензии нет.
- Последняя активность — 21 апреля 2026 (тестовый файл проверки PAT-доступа `test-info-mod.md`), то есть ~2,5 месяца тишины на момент аудита (июль 2026).
