# data7 — монорепо TSP-оптимизации: от диссертаций до MMO RPG и мультиагентного оркестратора

## Обзор

**data7** — самый крупный «исследовательско-инженерный» репозиторий профиля svend4. Его GitHub-описание (поле About) на деле не скромное, а перегруженное ключевыми словами и уже перечисляет все шесть подпроектов («info, задача коммивояжера, оптимизация, mmorpg, диссертации, энциклопедии, двунаправленная трансформация, 1. Meta-Orchestrator Switchboard … 6. Infrastructure & DevOps»). А вот отрендеренная титульная страница README озаглавлена «MMO RPG Optimization Systems» и раскрывает лишь один из подпроектов — именно она, а не описание, занижает реальный масштаб. Фактически это монорепозиторий из **шести взаимосвязанных подпроектов**, объединённых одной сквозной идеей: применение алгоритмов задачи коммивояжера (TSP) и многокритериальной оптимизации к самым разным доменам — научным текстам, игровому дизайну, мультиагентным ИИ-системам и профессиональным симуляторам.

Состав (по описанию самого репозитория и подтверждено аудитом):

1. **Meta-Orchestrator Switchboard** — «телефонная станция ар-деко 1920-х для мультиагентных ИИ-систем»: полноценный FastAPI-бэкенд (14 API-роутеров в `app/api` + `__init__.py`, PostgreSQL, Alembic, Redis, WebSocket) + React/TypeScript-фронтенд с Three.js.
2. **Paradigm 2: Professional Simulator** — симуляторы пяти профессиональных доменов (здравоохранение, логистика, производство, ритейл, социально-бытовые услуги) внутри бэкенда.
3. **MMO AI Bridge v1.1** — концепция «третьего глаза» для LLM через игровую визуализацию: прототип + мини-веб-приложение (`mmo_ai_bridge_web/`, server.py на 863 строки, Docker).
4. **Scientific Knowledge Management** — TSP-оптимизатор структуры диссертаций и двунаправленный трансформатор «диссертации ⇄ энциклопедии» (`dissertation_optimizer.py`, `knowledge_transformer.py`).
5. **TSP Algorithms & Multi-Agent** — библиотека TSP-алгоритмов (multi-depot, dynamic, stochastic, hierarchical, 2-opt, simulated annealing, ant colony, генетический — `backend/app/services/tsp_algorithms.py`, 1494 строки) и координатор мультиагентных систем.
6. **Infrastructure & DevOps** — docker-compose, Makefile, CI/CD (GitHub Actions), мониторинг Prometheus + Grafana, скрипты бэкапа.

Корневой README озаглавлен «MMO RPG Optimization Systems» и описывает только один из подпроектов (5 игровых систем: SmartQuestLog, AIDirector, BurnoutDetector, EconomyBalancer, SkillTreeOptimizer) — он **не отражает реальный масштаб репозитория**.

## Назначение и идея

Сквозная идея: **«оптимизация жизни» как универсальный метод**. Задача коммивояжера используется как метафора и рабочий инструмент для минимизации «когнитивной дистанции»:

- порядок глав диссертации → минимизация когнитивной нагрузки читателя (формализация `J(π) = Σ cognitive_distance(chapter_i, chapter_i+1)`);
- маршрут квестов в MMO → экономия 30–40% времени игрока (0.153 мс на 35 квестов, по заявлениям бенчмарков);
- маршрутизация задач между ИИ-агентами → Meta-Orchestrator;
- трансформация знаний: декомпозиция диссертаций в сегменты, агрегация в энциклопедические статьи и обратный синтез идей новых исследований.

Проект развивался «слоями»: сначала теория TSP для диссертаций (на русском, `dissertation_tsp_theory.md` ≈ 41 КБ теории с теоремами), затем перенос на игровой дизайн, затем ответ на критическую статью NVIDIA (HABR_ARTICLE_RESPONSE.md), концепция MMO как визуального моста для ИИ, и наконец — попытка собрать всё в production-подобную платформу.

## Как устроено (архитектура)

Три уровня зрелости кода в одном репозитории:

- **Корень**: ~90 markdown-документов (теория, спецификации из 8+ частей, отчёты фаз, самоаудиты) и ~9 автономных Python-прототипов без внешних зависимостей (в сумме ~5 700 строк): `dissertation_optimizer.py`, `knowledge_transformer.py`, `mmo_rpg_mechanics.py`, симуляции экономики и бенчмарки.
- **backend/** — FastAPI-приложение со слоистой архитектурой: `app/api` (14 роутеров + `__init__.py`), `app/services` (9 сервисов, включая TSP-библиотеку и координатор агентов), `app/simulators` (5 доменов, healthcare — 1000 строк), domain/infrastructure/auth/cache/middleware/websocket, Alembic-миграции, pytest-тесты (unit/integration/load/websocket), 9 файлов примеров API.
- **frontend/** — React 18 + TypeScript + Vite + Zustand + Three.js (@react-three/fiber) + Recharts, тесты Vitest и Playwright e2e.
- **Инфраструктура**: `docker-compose.yml` (postgres + backend + frontend; redis и celery закомментированы), `.github/workflows/ci-cd.yml` (линтеры black/isort/flake8/mypy, bandit/safety, unit+integration тесты с coverage, фронтенд-тесты), `monitoring/` (prometheus, grafana), `scripts/` (backup/restore/cron).

Подробнее — в [structure.md](structure.md).
