## Как собрано

Двухфазный рой ИИ-агентов:

1. **Аудит** — по одному агенту на репозиторий: чтение дерева файлов, исходников, README, коммитов, PR и raw-содержимого через веб-доступ к GitHub.
2. **Адверсариальная перепроверка** — второй слой агентов опровергал первый: сверял цифры, ловил заявления о «production-ready» на заглушках, проверял наличие лицензий/тестов/CI. Итог: 47 разборов исправлено, 13 подтверждено, 1 существенно переработан.
3. **Синтез** — таксономия из 14 тем, обзоры тем, портрет профиля, сочетания, вопросы, дорожная карта, индекс.

**Профиль в цифрах:** 61 репозиторий · средняя зрелость 2,28/5 · 32 экспериментальных, 13 завершённых, 8 почти пустых, 6 активных, 2 заброшенных · самые зрелые: `lorenzo`, `nautilus`, `infon`, `info150`, `meta2`.

## Оговорки

Аудит проводился по веб-доступу, **без `git clone` и без запуска кода** — выводы о работоспособности сделаны по чтению исходников. Оценки зрелости и статуса — экспертное суждение агентов. Профиль мог измениться после 3 июля 2026. Подробнее — в разделе «Методология и оговорки» титульной страницы.
