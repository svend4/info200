# info200 — Вики-энциклопедия GitHub-профиля `svend4`

На ветке `main` сейчас находятся только файл лицензии [`LICENSE`](LICENSE) и корневой `README.md`. Основное содержимое проекта — русскоязычная вики-энциклопедия по 61 публичному репозиторию профиля `svend4` — находится в невлитой ветке [`claude/agent-swarms-audit-wiki-266bh9`](https://github.com/svend4/info200/tree/claude/agent-swarms-audit-wiki-266bh9).

Энциклопедия собрана 2–3 июля 2026 года двухфазным роем ИИ-агентов (первичный аудит репозиториев + адверсариальная перепроверка без локального запуска кода).

## Сводка аудита (по `wiki/README.md` на ветке `claude/agent-swarms-audit-wiki-266bh9`)

- **Проверено репозиториев**: 61 (средняя зрелость — 2,28 / 5).
- **Распределение по статусам**: 32 экспериментальных, 13 завершённых, 8 почти пустых, 6 активных, 2 заброшенных.
- **Инженерная гигиена**: 52 без тестов, 57 без CI, 33 без лицензии.
- **Наиболее зрелые (уровень 4)**: `lorenzo`, `nautilus`, `infon`, `info150`, `meta2`.

## Технологический стек и запуск

Основной артефакт репозитория — статическая документация в Markdown и JSON-индексы в `wiki/_data/`, предназначенные для чтения на GitHub или в Markdown-просмотрщиках. Инструкций по установке зависимостей или запуску исполняемого кода в репозитории нет (скрипты `audit-swarm-workflow.js` и `synthesis-workflow.js` зафиксированы как артефакты проведённых роевых сессий).
