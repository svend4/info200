# Info200 — инженерная гигиена репозиториев

Заметки и обсуждения по общим вопросам качества репозиториев: лицензии, тестирование и CI. Открытая задача [№ 5](https://github.com/svend4/info200/issues/5) содержит результаты аудита и варианты дальнейшей политики.

Основные материалы проекта размещены в документации и связанных ветках; в корне сейчас нет исходного кода приложения.
